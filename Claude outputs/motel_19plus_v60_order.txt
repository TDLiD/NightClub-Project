### 0. 대원칙 (모든 기능에 공통 적용 — 이 규칙을 어기는 구현은 반려)
---------------------------------------------------------------------
1. 등장인물은 모두 성인(19세 이상). 기존 adult(n) 검사를 모든 19+ 메뉴 진입점에 적용.
2. 19+ 메뉴는 "체크인한 객실 안(ROOM area) + 파트너 동석" 일 때만 표시.
   클럽·스테이지·VIP·노래방·로비·복도·외부에서는 절대 노출 금지.
3. 동의는 "단계별·행위별". 앞 단계 동의가 다음 단계를 자동 허락하지 않음.
   (예: 속옷 술자리 OK ≠ 옷 벗기기 OK, 상의 벗기기 OK ≠ 하의 벗기기 OK)
4. 플레이어와 NPC 모두 언제든 [⏸ 잠깐] [✋ 그만] [↩ 다른 걸 하자] 가능.
   [✋ 그만] 은 즉시 현재 동작 중단 → 중립 포즈(나란히 앉기) 로 0.6초 블렌드 전환,
   NPC는 상황에 맞는 대사로 자연스럽게 마무리(분위기 페널티 없음, 신뢰 +1).
5. 만취는 동의가 아니다. 플레이어 NC.Life.tipsy ≥ 3.5 또는 NPC n.drunk / 술자리 누적 drinks ≥ 한도이면
   모든 신체 접촉·탈의·샤워 함께하기 메뉴 비활성 → NPC가 "물 마시고 쉬자 / 그냥 자자" 제안.
   (관리자 🧪 테스트 모드에서도 이 규칙은 유지 — v59와 동일)
6. 성행위 자체는 묘사·애니메이션하지 않는다. 그 지점은 "🌙 둘만의 시간" 시네마틱
   페이드아웃(암전 → 시간 경과 → 이불 속 대화 장면)으로 처리.
7. 노출 표현 상한 (렌더링 규칙):
   - 화면에 보이는 최소 착장 = 속옷(브라·팬티/드로즈) 또는 수건·가운·이불.
   - "알몸" 단계는 상태값으로만 존재하고, 렌더링은 이불/수건/김 서린 유리/실루엣/
     카메라 크롭(어깨 위)으로 가린다. 해부학적 노출 메시·텍스처는 만들지 않는다.
   - 이유: (a) 서비스 국가(한국 청소년보호법·정보통신망법, 인도네시아 UU 44/2008 포르노그래피법)에서
     노골적 노출은 서비스 중단·형사 리스크, (b) 현재 GLB 모델(Rocketbox/VALID)은 옷이 메시·텍스처에
     구워져 있어 실제 "벗은 몸" 메시가 없음 → 억지로 만들면 메시 깨짐 발생.
8. 19+ 메뉴 최초 진입 시 1회 확인 모달: "성인 전용 콘텐츠입니다. 만 19세 이상입니까?" + 성인인증 플래그
   (NC.account.adult) 저장. 추후 실제 본인인증 API 연결 지점만 함수로 분리(verifyAdult()).

### 4. 🎮 가위바위보 옷 벗기 게임 + 👗 옷 벗겨 주기 (단계별)
---------------------------------------------------------------------
공통 착장 레이어 (위에서부터 한 단계씩, 캐릭터별 의상에 맞게 자동 매핑):
  L0 외출복 전체 → L1 겉옷(재킷/카디건) → L2 신발·양말·액세서리 → L3 상의 → L4 하의
  → L5 속옷 → L6 "수건/이불로 가린 상태" (0장 7항: 화면상 최하단, 노출 렌더링 없음)

A. 🎮 가위바위보 옷 벗기 게임
  시작: [게임하자] → NPC 수락/거절/조건부("양말부터예요 ㅎㅎ", "속옷까지만") → 규칙 합의 화면
  규칙 설정(둘 다 확인해야 시작):
    · 판수: 3판 / 5판 / 7판 / 서든데스
    · 벌칙 상한: 겉옷까지 / 속옷까지 / L6(이불·수건)까지
    · 대체 벌칙 허용: 무알콜 원샷 / 칭찬하기 / 막춤 / 다음 노래 고르기 / 뽀뽀(동의 시)
  진행:
    1) 둘 다 손 내밀기 → 플레이어 선택(✊✋✌) / NPC는 성격 기반 확률 + 직전 패턴 학습
    2) "가위바위보!" 동시 공개 — 손 모양 포즈 실제 표시(finger pose), 승패 판정, 표정 리액션
    3) 패자는 "어떤 걸 벗을지" 스스로 선택(가장 바깥 레이어부터) 또는 대체 벌칙 선택
    4) 벌칙 상한 도달 시 자동 대체 벌칙, 상한 초과 진행은 불가
  NPC도 지면 벗거나 대체 벌칙 선택 — 성격별(대담: 바로 벗음 / 수줍: 대체 벌칙 선호 / 장난: 협상)
  언제든 [그만하자] → 게임 종료, 원하면 [옷 다시 입기] 한 번에 L0 복귀.
  기록: 승패·연승 대사("벌써 세 판 연속이에요?"), 다음 게임 시 NPC가 이전 패턴 언급.

B. 👗 옷 벗겨 주기 (남→여, 여→남 모두 가능. 한 단계 = 한 번의 동의)
  🙋 "벗겨 줘도 돼?" 물어보기 → 현재 레이어 1단계에 대해서만 동의 판정
    · 수락: 짝 애니메이션(마주 서기 → 손이 단추/지퍼/어깨끈 위치로 IK → 0.4초 페이드 중 레이어 교체)
    · 망설임: "불 좀 끄고요" / "천천히요" → 조건 충족(조명 dim, mood19↑) 후 재요청 가능
    · 거절: 즉시 중단, limits 에 기록, 같은 단계 재요청 시 압박 판정(신뢰↓·분위기↓)
  🔁 NPC가 먼저 "이것 좀 풀어 줄래요?" 요청하는 역방향 이벤트 포함
  L5 → L6 단계: 별도 강한 동의(NEED.undressFinal = 90, 신뢰 ≥ 80, mood19 ≥ 70, 비음주)
    수락 시 → 조명 자동 dim + 이불 덮기/수건 두르기 컷 → 카메라 어깨 위 크롭 →

### 12. 테스트 · 완료 기준
---------------------------------------------------------------------
1. 19+ 섹션이 객실 밖 어디에서도 안 보이는지 (클럽/노래방/로비/복도 각각 확인).
2. 체크인 → 혼자 샤워 → 같이 샤워 → 속옷 술자리 → 가위바위보 7판 → 단계별 탈의 L0→L6 →
   둘만의 시간 → 아침 → 원래 옷 → 체크아웃 전체 흐름 오류 0.
3. 각 단계에서 거절·그만·만취 분기가 동작하고 중립 포즈로 복귀하는지.
4. 가위바위보: 벌칙 상한 초과 불가, 대체 벌칙, NPC 성격별 반응, 손 모양 표시.
5. 탈의/착의 반복 20회 — 메시 깨짐·옷 떠다님·순간이동 없음, 체크아웃 후 기본 의상 복귀.
6. 모바일(iPhone) 메모리: 욕실 파티클·의상 변형본 로드 후에도 튕김 없음(파티클 수 모바일 1/3).
7. 기존 일반/로맨틱/기타 활동 전부 이전과 동일하게 동작.
8. 결과를 PC 프로젝트 폴더에 반영하고 변경 파일 목록·사용법을 한국어로 보고.

# 🪩 추억의 나이트 · 메타버스 v30

1990년대 감성 나이트클럽을 웹 3D로 옮긴 메타버스입니다. v2에서는 사람형 아바타(인물마다 얼굴이 다름), 밝은 조명, 4구역 공간, AI 부킹 NPC, 웨이터 팁 부킹, 미니게임, 공간 음향, WebRTC 근거리 음성을 추가했습니다.

## v30 변경 사항 — AI 캐릭터 4명 (참고 이미지 기반)
- **재숙**(기존 재숙_여사 → 이름 변경): 애시 브라운 단발 · 핑크 안경 · 네이비 세일러 칼라 재킷(핑크 트림·소매 라인) + 네이비 무릎 스커트 · 갈색 크로스백 · 네이비 플랫 슈즈.
- **혜정**(신규, 42): 긴 웨이브 흑발 · 네이비 잔꽃무늬 민소매 롱 원피스 · 금색 샌들.
- **Lena**(신규, 24세 성인 설정): 베이지 버킷햇 · 앞머리 있는 긴 웨이브 흑발 · 아이보리 니트 스웨터 · 세이지 그린 코듀로이 와이드 팬츠 · 베이지 스니커즈.
- **조여사**: 네이비 선 바이저(로고 없음) · 짧은 흑발 단발 · 페이즐리 반다나 · 네이비 긴소매 티 + 네이비 숏츠 · 네이비/화이트 러닝화.
- 아바타 새 요소(`avatar.js`): 모자 `bucket`·`visor`, `bandana`, 세일러 칼라 `sailor`, 크로스백 `bag`, 긴소매 `longSleeve`, 롱 기장 `maxi`, 하의 패턴 `bottomPattern`, 무늬 `floral`·`cord`·`knit`·`paisley`, 신발 `sandals`·`flats`, 안경 색 `face.glassesColor`.
- v29 실사 비율 전환 뒤 모자·신발이 단순하게 그려지던 문제 수정(모자 다시 표시, 스니커즈·부츠 디테일).

## v29 변경 사항
- **🕺 브루스 추실래요?** — 어느 장소에서나(테이블·VIP·바·통로·흡연실·2층 라운지·거리·노래방 로비·노래방 룸) 대화 칩에 표시. 앉아 있으면 둘 다 일어나 그 자리에서 추고, 끝나면 손님은 원래 자리로 돌아가 앉음. 블루스 곡으로 전환 후 끝나면 원래 곡으로 복귀(`karaoke.js`).
- **실사 비율**: 큰 머리·큰 눈의 인형 비율(TOON)을 끄고 실사 비율·실사 얼굴 묘사로 전환(`avatar.js`). 여성 손님도 남성(v25)처럼 실제 여성복 조합·무광 원단·자연스러운 메이크업으로, 아이돌 무대 룩 비율은 45%→15%.
- **개성 있는 이름 캐릭터 10명**: 지현·수빈·민재·하늘·예린·도현·서연·지우·재숙_여사·조여사에게 각자 다른 헤어·의상·소품·얼굴을 지정(`data/npcs.json`). 재숙·조여사 직업 표기 오류 수정.
- **왼쪽 원형 무대 = 폴 댄스**: 크롬 폴 2개, 폴댄서 2명이 32박 주기로 걷기→회전→바디 웨이브→회전→매달리기(`stage.js`, `motion.js` 의 pole 동작). 의상은 폴 피트니스 스포츠 크롭+숏츠.
- **조명**: 접속할 때마다 기본 = 💡 전등만. 새 테마 **⚡ 강한 네온등** — 실내등·환경광을 낮춘 어두운 무대를 강한 네온 무빙라이트가 무대 위를 훑음(`world.js`).
- 프로필 카드 취미가 `[object Object]` 로 나오던 버그 수정(`service.js`).
- **3D 모델(VRM) 연결**: 서진·수아·하린은 `models/sample_girl.vrm` 3D 모델을 씁니다. 다른 캐릭터도 같은 수준으로 하려면 VRoid Studio(무료) 등으로 만든 `.vrm` 파일을 `public/models/` 에 넣고 `data/npcs.json` 의 해당 캐릭터에 `"model": "models/파일명.vrm"` 을 추가하세요(모바일 메모리를 고려해 3~5개 이내 권장).

## v28 변경 사항 — 모바일 중심 최적화
- **노래방 등 입장 시 로그인 화면으로 돌아가던 문제**: 원인은 모바일 브라우저의 메모리 초과로 인한 탭 재시작. 절차적 텍스처가 재질마다 따로 GPU에 올라가던 것(홀 기준 244개, 약 220MB)을 공유하도록 바꿔 **59개**로 줄임(`gfx.js`). 저사양(모바일)은 노멀·러프니스 맵 생략.
- **이어서 입장**(`js/mobile.js`, 신규): 게임 상태를 4초마다 저장 → 탭이 다시 열리면 「▶ 이어서 입장」(모바일은 3초 뒤 자동). 로그아웃하면 저장 삭제. WebGL 컨텍스트 손실 시 자동 새로고침 후 이어서 입장.
- 조명 추가·삭제로 전체 셰이더가 재컴파일되던 카메라 플래시를 상주 조명으로 교체(`episodes.js`, 저사양은 생략).
- LED 배경 영상: 모바일 기본 꺼짐, 홀 밖(노래방·VIP·흡연실·거리)·백그라운드에서는 디코딩 정지(`world.js`).
- 적응형 해상도(프레임 저하 시 자동으로 낮춤), 백그라운드 전환 시 음악 일시정지, 고화질 선택 시 경고.
- 세로 화면 시야각 자동 보정(`core.js`), 실내에서 카메라가 벽 밖으로 나가지 않게 방 상자 안으로 제한 + 막히면 방 가운데 쪽으로 시점 회전(`main.js`).
- 터치: 두 손가락 핀치 줌, 탭 이동 허용 오차 확대, 길게 누르기·더블탭 확대 방지.
- 모바일 화면 재배치: 미니 음악 플레이어(오른쪽 위), 파티 버튼·손님 리스트 겹침 해소, 이모트는 😀 서랍, 대화 선택지는 아래 시트, 노래방 버튼 가로 정렬, 프로필 카드 상단 고정, 입력창 16px(iOS 확대 방지), 가로 화면 배치.

## 실행
```bash
npm install          # express, ws, three(로컬 폴백)
npm start            # http://localhost:3000
```
- 온라인(실제 접속자) / 솔로(AI 손님)는 시작 화면에서 고릅니다.
- 서버 기능 없이 화면만 보려면 `http://localhost:3000/?mode=demo` 로 엽니다.
- AI 자유 대화를 쓰려면 `ANTHROPIC_API_KEY=...`(또는 `OPENAI_API_KEY`)를 설정한 뒤 실행합니다. 키가 없으면 로컬 대사 엔진이 대신 답합니다.

## 운영 전 확인
- **성인 인증**: 기본값(mock)은 법적 의미의 성인 인증이 아닙니다.
- **HTTPS**: 마이크(음성 채팅·음성 입력)는 HTTPS 또는 localhost에서만 동작합니다.
- **TURN 서버**: STUN만으로는 일부 네트워크에서 음성이 연결되지 않습니다.
- **음성 인식**: Chrome의 음성 인식은 음성을 구글 서버로 보냅니다. 개인정보 처리방침에 적어 두어야 합니다.

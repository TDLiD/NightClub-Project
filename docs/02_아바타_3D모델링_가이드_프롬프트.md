# 02. 아바타 3D 모델링 제작 지침서 + 텍스처/컨셉 생성 프롬프트

> 현재 웹 버전은 `public/js/avatar.js` 의 **절차적 아바타**(관절 리그 + 캔버스 얼굴 텍스처)로 동작합니다.
> 아래 지침은 실제 GLB/FBX 모델로 교체하거나 Unity/Unreal 버전을 만들 때의 제작 기준입니다.

## 1. 공통 사양

| 항목 | 웹(Three.js) | PC/콘솔(Unity·Unreal) |
|---|---|---|
| 폴리곤 | 8k~15k tris/인 (동시 50명) | 30k~60k tris |
| 머티리얼 | 2~3개(바디·헤어·의상) | 4~6개 |
| 텍스처 | 1024² (얼굴 512² 별도 아틀라스) · KTX2 압축 | 2048~4096² |
| 포맷 | glTF 2.0(.glb) + Draco/Meshopt | FBX / glTF |
| 리그 | Mixamo/Humanoid 호환 본 이름, 손가락 3마디 | Unity Humanoid / UE5 Mannequin 리타깃 |
| 블렌드셰이프 | ARKit 52 중 최소 15개(eyeBlink L/R, mouthSmile L/R, jawOpen, browInnerUp, browDown L/R, cheekPuff, mouthPucker, eyeWide L/R, mouthFrown L/R, viseme aa/oh/ee) | ARKit 52 전체 + 비셈 15 |
| 스케일 | 1unit = 1m, 발바닥 원점, +Z 정면 | 동일(UE는 cm) |

## 2. "나이트클럽 조명에서 예뻐 보이는" 핵심 규칙
1. **피부 SSS 대신 랩 라이팅**: 강한 컬러 조명(핑크·시안) 아래 피부가 회색으로 죽지 않도록 Subsurface 대신 *wrap diffuse(0.3)* + 따뜻한 베이스 컬러. 웹은 `MeshStandardMaterial` roughness 0.55~0.6.
2. **림 라이트 친화적 실루엣**: 헤어 끝·어깨선·드레스 밑단에 분명한 외곽. 머리카락은 카드 방식 + 알파 클립(블렌드 금지 → 정렬 문제).
3. **반사 소재 1개 이상**: 시퀸·새틴·벨벳·가죽 중 하나는 metalness 0.2~0.4 / roughness 0.3 → 미러볼 반사점이 옷에서 반짝임.
4. **이미시브 액센트**: 귀걸이·네일·스니커즈 솔에 약한 emissive(0.2~0.5) → 블룸이 걸려 "클럽감".
5. **눈 하이라이트 고정**: 어두운 구역에서도 눈이 살아 보이게 각막에 고정 스페큘러(텍스처로 그린 하이라이트). 웹 얼굴 텍스처가 이 방식.
6. **얼굴 대비**: 아이라인·눈썹·립을 실제보다 10~20% 진하게(멀리서도 표정 인식). 볼터치는 조명 색과 섞여도 보이게 채도 높게.
7. **의상 컬러 대비**: 조명 주색(마젠타·시안·옐로·바이올렛)과 겹치지 않는 보색·무채색을 섞어 아바타가 배경에 묻히지 않게.

## 3. 캐릭터 다양성(얼굴이 모두 다르게)
| 파라미터 | 범위 | 효과 |
|---|---|---|
| faceW / jaw | 0.85~1.15 | 얼굴 폭·길이 |
| eyeSize / eyeTilt / eyeGap | 0.7~1.3 / ±0.2 / ±0.05 | 눈 크기·눈꼬리·미간 |
| lid | 0/1 | 쌍꺼풀 |
| browThick / browTilt / browArch | — | 눈썹 인상(순함↔날카로움) |
| lipW / lipFull / lipColor | — | 입 크기·두께·색 |
| nose | 0.7~1.3 | 코 크기 |
| blush / liner / shadow | — | 메이크업 |
| freckles / mole / beard / glasses / earring | — | 개성 소품 |
| hairStyle (11종) · hairColor | — | 실루엣 |
→ 실제 모델에서도 같은 축을 **블렌드셰이프(체형/얼굴형)** 로 만들어 두면 모델 1~2개로 수백 가지 얼굴 생성 가능.

## 4. 제작 파이프라인 (권장)
1. 컨셉 시트(아래 프롬프트) → 2. 베이스 바디(MetaHuman / Character Creator 4 / VRoid) → 3. 의상(Marvelous Designer) → 4. 리토폴로지·LOD(LOD0 100% / LOD1 50% / LOD2 20%)
5. 텍스처(Substance Painter, 클럽 HDRI로 룩뎁) → 6. 리깅·블렌드셰이프 → 7. glTF 익스포트(KTX2+Meshopt) → 8. 웹 검증(`three/examples/jsm/loaders/GLTFLoader`)

> 웹에 적용할 때: `avatar.js` 의 `create()` 가 반환하는 `userData.rig` 와 같은 관절 이름(hips/torso/neck/head/shL/elL/shR/elR/legL/knL/legR/knR)에 본을 매핑하면 `motion.js` 를 그대로 재사용할 수 있습니다.

## 6. 검수 체크리스트
- [ ] 클럽 3대 조명(핑크·시안·옐로) 각각에서 피부가 회색/녹색으로 죽지 않는가
- [ ] 10m 거리에서 표정(웃음/쑥스러움)이 구분되는가
- [ ] 앉기 포즈에서 치마·재킷 관통이 허용 범위인가
- [ ] 50명 동시 렌더 시 모바일 30fps(LOD/텍스처 압축)
- [ ] 미성년자로 보이는 체형·의상·소품이 없는가

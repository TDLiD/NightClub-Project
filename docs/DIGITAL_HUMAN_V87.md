# MettaBus_1 디지털 휴먼 업그레이드 — 1단계 보고서 (v87)

기준: Epic Games MetaHuman(Character Creator + Animator). 원칙: 엔진 교체 없이 현재 구조(three.js r128 · 웹 브라우저 · GLB)에서 가능한 최고 품질을 먼저 구현.

## 2. 이번 단계에서 구현한 것 (전원 적용: 플레이어 · NPC · 직원 · 다른 접속자)

1. **인형 0명** — unique.js 교체 후보에서 체형 변형 항목 제외. 검사: 보이는 35명 전원 실사 모델(절차적 0명).
2. **얼굴 개성(Identity) — 새 파일 `js/digitalhuman.js`**
   사람마다 고정된 값(아이디 해시)으로 얼굴 뼈를 조정: 광대 높이·폭, 턱 길이·앞뒤·폭, 눈썹 높이·기울기, 입 폭, 윗·아랫입술 두께, 좌우 비대칭. 단위는 눈 사이 거리(IPD) 비율, 과장 없음. 같은 바탕 모델을 여러 명이 써도 골격이 달라 보임.
3. **LOD(거리용) 모델 얼굴 연기** — 블렌드셰이프가 없는 모델도 얼굴 뼈로 눈 깜빡임 · 말할 때 턱 벌림 · 웃음(입꼬리·광대) · 놀람(눈썹) · 찡그림. 측정: 말하기 시 아랫입술 9mm 하강, 웃음 시 입꼬리 3mm 상승.
4. **살아 있는 얼굴(미세 표정)** — 사람마다 빈도·크기가 다른 작은 눈썹 들썩임·입꼬리 변화(모든 모델).
5. **피부 디테일** — 피부 영역에만 모공 디테일 노멀(UV 46회 반복) + 거칠기 변화(모델 원래 노멀맵 위에 합성). 옷에는 적용 안 됨.
6. **각막 광택** — 별도 안구 메시가 있는 모델(VALID)은 젖은 눈 광택(거칠기 0.12).
7. 뼈는 매 프레임 '기준 + 변화'로 다시 써서 누적·떨림이 없음. 16m 밖 인물은 개성만 적용하고 매 프레임 계산은 생략(성능).

## 4. 남은 한계 — 솔직한 평가

- **현재 모델은 MetaHuman 수준이 아닙니다.** Rocketbox/VALID는 2010년대 게임용 메시·텍스처(얼굴 1–2K, LOD 256–512px)입니다. 셰이더·뼈 조정으로 '조금 더 사람답게'는 가능하지만, 근거리 MetaHuman 같은 얼굴 구조·모공·머리카락은 **새 자산 없이는 불가능**합니다.
- three.js r128에는 진짜 다층 SSS(스크린 공간 확산), 가닥 단위 머리카락(그룸), RigLogic(MetaHuman 얼굴 뼈 구동), 듀얼 쿼터니언 스키닝이 없습니다. 근사(wrap SSS, 알파 카드 머리, ARKit 블렌드셰이프, 선형 스키닝)만 가능합니다.
- VALID 모델의 LOD 판에는 얼굴 뼈도 블렌드셰이프도 없어 거리에서 깜빡임이 안 됩니다(시선만 움직임).
- 머리카락 이방성 하이라이트, 천 시뮬레이션, 모션 매칭은 이번 단계에 없습니다.

## 5. MetaHuman 실제 적용 경로 (다음 단계 · 외부 자산 필요)

라이선스: UE 5.6부터 MetaHuman은 Unreal Engine EULA로 바뀌어 **다른 엔진·도구에서도 사용 가능**(연 매출 100만 달러 미만 무료).

1. **제작(사용자 PC, Unreal Engine 5.6+ 의 MetaHuman Creator)** — 인물별로 얼굴·체형·피부·헤어·옷 생성(다양한 인종·나이·체형). 웹 군중용으로는 인물 수 × 용량이 핵심 제약.
2. **내보내기** — 몸+얼굴 메시를 FBX로(LOD1~LOD3 권장), 얼굴은 ARKit 52 블렌드셰이프로 굽기(Blender MetaHuman → ARKit 베이크), 텍스처 2K(근거리)/1K/512(LOD).
3. **변환** — GLB + meshopt 압축 + WebP 텍스처, 인물당 고화질 3–5MB 이하 목표.
4. **연결** — `manifest.json` 의 models 에 추가만 하면 됨. humanglb.js 는 이미 MetaHuman 뼈 이름(pelvis·spine_01~05·upperarm_l·thigh_l·index_01_l…)과 ARKit 블렌드셰이프 이름을 인식합니다. digitalhuman.js 의 얼굴 개성은 Biped 얼굴 뼈 대신 블렌드셰이프 조합으로 확장해야 합니다(다음 단계 작업).

이 경로의 2–3단계(변환 스크립트)는 실제 MetaHuman 파일이 있어야 시험할 수 있어 이번에 만들지 않았습니다.

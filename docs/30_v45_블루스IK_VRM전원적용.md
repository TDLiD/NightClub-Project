# v45 — 노래방 동행 버그 · 블루스 팔 동작 · 모든 여성 인물 VRM 캐릭터화

## 1. 노래방에 부킹 상대와 들어가면 상대가 앉은 자세로 돌아다니던 버그
- 원인: 별빛 노래방(거리 건물)에서 방에 들어갈 때 동행(`KS.comp`)의 `stay === 'outing'`이 그대로 남아,
  `outside.js`의 "따라다니기" 틱이 노래방 소파에 앉힌 뒤에도 계속 위치를 옮겼음 → 앉은 자세(`u.seated`)로 미끄러지듯 이동.
- 수정
  - `outside.js`: 노래방 룸 안(`NC.Karaoke.inRoom`)이거나 `n.karaoke`, `state === 'seated'`이면 따라다니지 않음.
  - `npc.js`: 안전장치 — 상태가 `seated`/`talk`/`blues`가 아닌데 앉은 자세가 남아 있으면 자동으로 일으켜 세움.

## 2. 블루스 동작(귓속말·허리·턴·딥·이마·볼·안기·백허그·키스, 프리미엄 동작)의 로봇 같은 팔
- 원인(측정): v44는 손 목표를 contact.js의 관절 각도 경사하강으로 끌고 갔고, 팔을 놓은 뒤에 상체를 숙이고 몸을 당겨서
  - 손이 목표에서 15~29cm 벗어났고,
  - 팔꿈치가 최대 **219°**까지 꺾였으며(백허그·키스),
  - 프레임 사이 팔 회전이 평균 5~9°, 최대 160°씩 튀었음.
- 수정(`couple.js`, `contact.js`, `motion.js`)
  - 손은 **해석적 2관절 IK**로 직접 놓음. 목표점은 **임계 감쇠 스프링**으로 따라가고(순간이동 없음),
    팔꿈치는 **145°까지만** 굽으며, 다 펴지는 거리에서는 **소프트 IK**(살짝 굽힌 채 멈춤).
  - 팔꿈치 회전각(스위블)은 이전 값에서 초당 2.6rad 이하로만 이동 → 팔이 갑자기 뒤집히지 않음.
  - 감싸 안기(등 뒤·앞 허리)에서 아래팔이 상대 몸을 뚫으면 손 목표를 상대 옆구리 쪽으로 조금씩 미끄러뜨림(사람 팔이 옆구리를 돌아 감싸듯).
  - 순서 변경: 몸 간격 조정(contact) → 숙임·까치발·고개 → 체중 이동·호흡 → **마지막에 팔 IK**.
  - IK가 잡고 있는 팔은 motion.js가 안무 자세로 다시 끌지 않음(오일러 보간으로 생기던 꺾임 제거),
    contact.js는 그 팔에 대해 남은 관통만 아주 작게 보정.
- 결과(헤드리스 측정, 같은 커플·같은 동작)

| 항목 | v44 | v45 |
|---|---|---|
| 손 목표 오차(중앙값) | 0.10~0.28 m | 0.04~0.09 m (안기·백허그 0.15~0.17: 옆구리로 감싸는 위치) |
| 팔꿈치 최대 굽힘 | 219° | 145° 이하 |
| 프레임당 팔 회전(중앙값) | 3~9° | 1~3° |

## 3. 모든 여성 인물을 하린·서진 같은 3D(VRM) 캐릭터로
- 시작 후 여성 NPC 전원(페르소나 + 손님 + DJ 루나·바텐더)에게 `models/sample_girl.vrm`을 차례로 입힘(한꺼번에 파싱하면 화면이 멈추므로 0.25초 간격 큐).
- 파일은 한 번만 내려받아(ArrayBuffer 캐시) 인물마다 따로 파싱.
- 인물마다 다르게(`vrm.js` `style()`)
  - 피부 톤, 눈동자 색, 눈썹 색, 머리·상의·하의·신발 색(npcs.json의 look 값)
  - 헤어: 샘플 VRM 원래 머리 모양을 유지하고 색만 바꿈. 단발·포니테일 등을 덧붙이는 기능은 시험해 봤지만 원래 VRoid 머리보다 품질이 떨어져 기본은 꺼 둠(`style.hairShapes`). 헤어 모양까지 다르게 하려면 VRoid Studio에서 만든 VRM 파일을 더 넣어야 함
  - 옷 무늬: 시퀸·메탈릭·호피·스트라이프·도트·체크·니트·플로럴·그래픽·레더(90년대 클럽 룩)를 원래 옷 텍스처 위에 합성
  - 평소 얼굴: 성격·얼굴 설정에 따라 눈매(살짝 감은 고양이 눈), 입꼬리, 눈썹 각도를 블렌드셰이프 기본값으로
- 성능: 데스크톱은 전원, 저사양·모바일은 가까운 순서로 최대 `vrmLiteMax`(기본 6)명.
- 끄기: 주소에 `?procedural` · npcs.json `"vrmAll": false`(이 경우 예전처럼 model 지정 페르소나만).
- **남성 인물**: 현재 남성용 VRM 파일이 없어 기존 실사 절차적 캐릭터를 유지. 남성 VRM을 `models/`에 넣고
  npcs.json에 `"vrmModels": { "m": "models/파일.vrm" }`를 추가하면 같은 방식(인물별 스타일 포함)으로 자동 적용됨.
- 샘플 VRM 라이선스: three-vrm-girl(pixiv) — 메타데이터상 누구나 사용, 상업 이용 허용.

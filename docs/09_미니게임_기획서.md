# 09. 아이스브레이킹 미니게임 3종 — 규칙 & 개발 기획서

> 구현: `public/js/minigames.js` · 데이터 `public/data/minigames.json` · 진입: 대화 패널 "🎲 미니게임" 칩 또는 LLM `action:"game"`
> 공통: 대화 중인 NPC와 1:1로 진행, 대화 패널은 잠시 숨김, 종료 시 결과를 대화 로그와 호감도에 반영.

---
## 🎡 1. 진실게임 룰렛
**목표**: 서로에 대한 '진짜 정보'를 교환해 대화 소재를 만든다.

### 규칙
1. 4라운드. 홀수 라운드 = 내가 돌림(→ NPC가 답함), 짝수 라운드 = NPC가 돌림(→ 내가 답함).
2. 룰렛 9칸: 첫인상 · 연애관 · 취향 · 흑역사 · 이상형 · 최근 고민(질문 6칸) · **벌칙: 원샷(가상)** · **벌칙: 애교 3초** · **패스권**.
3. 질문 칸 — 내 차례: NPC가 페르소나 `truths[카테고리]` 로 답하고 쑥스러워함(shy 모션, +1). NPC 차례: NPC가 `asks[카테고리]` 질문 → 내가 입력 → 규칙 엔진 분석 Δ×0.5 + 8자 이상이면 +2.
4. 벌칙 칸 — 돌린 쪽의 '상대'가 수행(가상 술잔 drink 모션 / 애교 shy 모션), +1.
5. 패스 칸 — 그 라운드 스킵.
6. 종료: 🪙+15, 호감 +(6 + 라운드 누적).

### 개발 메모
- 캔버스 휠: 3.2초 ease-out-cubic, 칸 경계 통과 시 tick 효과음, 포인터는 12시 방향.
- 결과 칸 인덱스 = `floor(((−angle mod 2π)+…) / (2π/N))`.
- 음주는 가상 연출만(실제 음주 유도 문구 금지).

## ⚖️ 2. 밸런스 게임
**목표**: 취향 '싱크로율'로 공감대 확인 + 다른 선택에서 대화 거리 만들기.

### 규칙
1. 문항 8개 중 랜덤 5개. 두 선택지 동시 공개.
2. NPC 선택: 페르소나 `balance[id]` 고정값 → 없으면 성격(trait) 기본값(15% 확률로 반대 = 의외성).
3. 일치: 호감 +3, 🪙+4, "통했다!🙌"(bigUp 모션) / 불일치: 호감 −1, "그건 설득 좀 해 봐요"(think 모션).
4. 결과: 싱크로율 % — 80↑ "천생연분?!", 40↑ "꽤 잘 맞네요", 그 외 "정반대의 매력". 60↑이면 NPC 만세.

### 개발 메모
- 문항 추가는 json 한 줄: `{id, a, b, trait:{outgoing:'a',…}}` + 페르소나별 `balance` 지정(선택).
- 불일치 직후 대화로 돌아가면 "왜 그걸 골랐어요?"가 자연스러운 다음 대화 → 로그에 남김.

## 💃 3. 커플 댄스 챌린지 (리듬 게임)
**목표**: 같이 몸을 움직이며 어색함을 깨고, 아바타 댄스 연출을 즐긴다.

### 규칙
1. 현재 음악 BPM(118) 기준, 4박 카운트다운 후 32박 동안 화살표 노트가 떨어짐(8분음표 패턴 5종 랜덤 조합).
2. 판정선에서 ← ↓ ↑ → (모바일: 화면 버튼) 입력. PERFECT ±90ms(2점) / GOOD ±170ms(1점) / MISS.
3. 진행 중 두 아바타가 stageDance(앉아 있었다면 잠시 일어남).
4. 결과: 내 정확도 = 점수 / (노트×2). 파트너 정확도 = 성격별 실력(playful .93, outgoing .86, cool .78, shy .62) × 0.9~1.05.
   커플 싱크로율 = (내 + 파트너)/2. 보상: 호감 +14×정확도(30% 미만이면 −3), 🪙 40×정확도.

### 개발 메모
- 타이밍 기준은 `AudioContext.currentTime` + 오디오 스케줄러의 시작 시각(`beatTime(n)`) → 화면 프레임 드랍과 무관하게 정확.
- 캔버스 360×400, 노트 속도 260px/s, 판정선 y=350.
- 키 입력은 capture 단계에서 가로채 이동 키와 충돌 방지(`NC.Games.active` 동안 이동 정지).

---
## (확장 후보) 🍻 술자리 미니게임 — "3·6·9 클럽 버전"
- 순서대로 숫자를 외치고 3·6·9가 들어가면 숫자 대신 '짠'(C 키). 틀리면 가상 벌칙(애교/원샷 모션).
- 박자(BPM)에 맞춰 차례가 넘어가 리듬 게임 엔진 재사용 가능. 실제 음주 권유 문구·연출은 넣지 않습니다.

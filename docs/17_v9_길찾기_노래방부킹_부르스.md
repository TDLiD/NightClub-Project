# v9 — 클릭 길찾기 · 노래방 웨이터/부킹 · 부르스

## 1. 클릭 이동 길찾기 (`public/js/pathfind.js`)
| 항목 | 내용 |
|---|---|
| 지도 | `W.rects`·`W.circles`를 0.35m 격자로 굽고, 캐릭터 반경 0.42m만큼 부풀려 못 가는 칸 표시. 처음 쓸 때 한 번만 생성(~10ms). |
| 탐색 | A*(8방향, 대각선 모서리 끼임 방지, 이진 힙). 1회 1~6ms. |
| 다듬기 | 시야가 트인 가장 먼 점으로 건너뛰어 꺾이는 점만 남김. 통로를 자연스럽게 따라 걸음. |
| VIP | 유리문은 다가가면 열리므로 통과 가능 칸으로 처리. 잠긴 방은 클릭할 때 안내. |
| 클릭 해석 | 클릭 광선이 VIP 정면 유리(z=9.2)를 사람 키 높이로 통과하면 해당 방 입구로 이동. 목적지가 가구 위라면 가장 가까운 빈 칸으로 보정하고, 도착 후 가장 가까운 좌석에 자동 착석(바 의자·소파·테이블). |
| 막힘 복구 | 1.2초 이상 제자리면 현재 위치에서 한 번 다시 탐색. |
| 적용 범위 | 플레이어 클릭 이동, `NC.NPC.planPath`(웨이터 서비스, VIP 동행, NPC 이동). 노래방·화장실·흡연실 같은 별도 공간 안에서는 직선 이동. |
| 표시 | 도착 지점에 분홍 링 마커. |

## 2. 노래방 웨이터 호출 · 부킹 (`public/js/karaoke.js` v9 구역)
1. 하단 바 「🙋 웨이터 호출」(또는 손님 대화 칩) → 벨 → 클럽 웨이터 한 명이 노래방 문으로 들어와 테이블 옆에 섬.
2. 메뉴는 다음과 같습니다.
   - 🍺 맥주 세트 🪙12
   - 🍉 모둠 과일 안주 🪙15
   - 🥃 양주 세트 🪙40
   - 🥤 음료수 🪙3
   - 💃 부킹 부탁해요
   - 🧾 팁 🪙5 (부킹 성공률 +5%, 최대 +15%)

   주문하면 테이블에 소품이 놓이고, 같이 있는 손님의 호감도가 오릅니다.
3. **부킹 진행**
   - 스타일을 고릅니다: 상냥·귀여움 / 시크 / 흥 많음 / 아무나.
   - 팁을 고릅니다: 🪙10이면 성공률 약 60%, 🪙30이면 약 90%.
   - 7초 뒤 노크 소리와 함께 여성 손님이 입장해 소파에 앉고, 성격에 맞는 첫인사로 대화창을 엽니다.
   - 첫 호감도: 최소 42에 팁 보너스(+3 또는 +6)를 더합니다.
   - 실패하면 팁 절반을 돌려줍니다. 방당 최대 3명이고, 첫 손님은 「한 곡 불러 줄래요?」(NPC 열창)도 가능합니다.
4. 퇴장 시 손님과 웨이터는 모두 클럽으로 돌아갑니다.

## 3. 부르스 (슬로댄스)
- 손님 대화 칩 「🕺 부르스 출래요?」를 누릅니다. 호감도 45 미만이면 손님이 거절합니다(−1).
- 수락하면 다음이 진행됩니다.
  - 반주: 발라드(시크한 성격은 R&B)
  - 자세: 둘이 마주 보고 천천히 흔들기. 리드는 손을 허리에, 상대는 어깨에 올립니다(`motion.js` `blues`).
  - 카메라: 측면 클로즈업
  - 처음 출 때 호감도 +3
- 대화 칩이 부르스 전용으로 바뀌고, 행동마다 상대의 **동의(호감도)**에 따라 반응합니다.

| 행동 | 수락 조건 | 수락 반응 | 거절 반응 |
|---|---|---|---|
| 🤗 꼭 안아 주기 | 55↑ | +2, 수줍음 | −1 |
| 💋 키스하기 | 80↑ · 4초 이상 춤 | +5(첫 키스) / +2, 서로 기울여 입맞춤 | 60~79: 고개 돌림 −1 / 60 미만: 밀침 −6, 춤 중단 |
| 🍑 엉덩이 만지기 | 없음 (90↑ · 키스 후엔 손을 허리로 돌려놓음 −2) | — | 뺨 −10, 춤 중단 |
| 🫳 가슴 만지기 | 없음 (92↑ · 키스 후엔 손목을 잡고 제지 −4) | — | 뺨 −15, 춤 중단 |
| 👚 옷 벗기기 | 없음 (90↑ · 키스 후엔 농담으로 넘김 −3) | — | 뺨 −15, 춤 중단 |
| ⏹ 부르스 그만 | — | 소파로 돌아감 | — |

- 뺨을 2번 맞거나 호감도가 25 미만이 되면 손님이 "저 먼저 갈게요"라고 하고 방을 나갑니다(재부킹 3분 제한).
- 원하지 않는 스킨십은 항상 역효과를 냅니다. 노출 표현은 없으며, 옷 벗기기는 늘 거절되거나 농담으로 넘어갑니다.
- 제스처 추가(`motion.js`): `slap`(뺨), `push`(밀침), `flinch`(움찔). 효과음 `slap`(`audio.js`)도 추가했습니다.

# 08. 웨이터 NPC 부킹 메커니즘 (팁 → 스타일 매칭 → VIP 룸 안내)

> 구현: `public/js/waiter.js` · 데이터 `public/data/waiter.json` · 서버 룸 잠금 `server.js (roomClaim/roomRelease/zone)`
> 🪙 클럽 코인은 **현금 가치가 없는 게임 재화**입니다(출석 +50, 스테이지 댄스 8초당 +1(세션 최대 60), 미니게임·엔딩 보상). 현금 결제 연동을 붙일 경우 확률형·사행성 규제 검토가 필요합니다.

## 1. 등장인물
| 웨이터 | 위치 | 행동 |
|---|---|---|
| 번개 ⚡ | 통로 중앙 스테이션 (1.5, 5.3) | 고정 대기, 다가오면 쳐다봄 |
| 나이스 | 통로 순찰(x −18 ↔ 18) | 왕복하며 두리번(lookAround) |
둘 다 조끼+나비넥타이 유니폼, 이름표 금색. E 키로 호출.

## 2. 대화 트리 (Dialogue Tree)
```
root  "어서 오십쇼~! 오늘 밤 책임질 웨이터 '번개'입니다 ⚡" (꾸벅)
 ├─ 💌 부킹 부탁해요 ─────────► style
 ├─ 🚪 VIP 룸 현황 ──────────► rooms ("VIP1 🟢 비어 있음 · VIP2 🟡 사용 중 · VIP3 🔒 예약됨") ─► style / end
 ├─ 💰 팁만 드릴게요(🪙5) ────► tipOnly (단골도 ★+1, 다음 매칭 보너스) ─► end
 └─ 괜찮아요 ────────────────► end
style  "어떤 스타일로 모실까요?"
 ├─ 🎉 활발한 분 / 🙈 수줍은 분 / 😎 시크한 분 / 😜 유머러스한 분 / ⚡ 번개 추천(아무나)
 └────────────────────────────► gender
gender "원하시는 분 성별 있으세요?"  여성분 / 남성분 / 상관없어요 ─► tier
tier   "팁 주시면 발에 땀나게 뛰어 봅니다~"
 ├─ 🪙10 기본 (성공 60%)
 ├─ 🪙30 프리미엄 (성공 85%, 시작 호감 +5)
 ├─ 🪙50 VIP 확정 (성공 100%, 시작 호감 +10, 🍾 샴페인)
 └─ 다음에 할게요 ─► end
   ↓ (코인 차감)
searching "한 바퀴 돌고 오겠습니다! 💨" (두리번, 1.6초)
   ├─ 코인 부족 ───────► noMoney  ("스테이지에서 춤추면 모여요")
   ├─ 빈 룸 없음 ──────► roomsFull (전액 환불)
   ├─ 매칭 실패/거절 ──► matchFail (½ 환불) ─► style / end
   └─ 성공 ────────────► matchOk "찾았습니다! 수아님이 VIP 2번 룸에서 기다리십니다 👉" (가리키기)
                           → 에스코트 → 착석 → 상대 입장 → 대화 시작
```

## 3. 매칭 알고리즘 (`waiter.js match()`)
```
후보 = 페르소나·손님 NPC 중
        ¬예약됨 ∧ ¬착석 ∧ ¬대화중 ∧ 쿨다운 끝 ∧ (성별조건 충족)
        ∧ (화면에 활성  ∨  온라인 모드의 페르소나)

score(n) = 스타일점수
         + (n이 페르소나 ? tier.personaBias × 30 : 0)
         + n.mood × 5                     # 오늘 기분 −1/0/+1
         + 단골도 rep × 2                  # 팁만 주기·엔딩으로 상승 (최대 10)
         + random(0~15)                   # 의외성
         − (최근 2분 내 거절했으면 40)

스타일점수 = 'any' → 30 / 정확히 일치 → 60 / 인접 성향 → 20 / 그 외 0
인접: outgoing↔playful, shy↔cool

best = argmax score
if best 없음 or score < 25          → 실패(½ 환불)
if rand > tier.success + rep×0.02   → 거절(½ 환불, best.rejectedAt = now)
room = 빈 VIP 룸(가운데 → 왼쪽 → 오른쪽 우선)
       온라인: 서버에 roomClaim(room) — 다른 사람이 있거나 잠겨 있으면 false → 전액 환불
성공 → best.booked = true, 룸 잠금, 에스코트 시작
```

## 4. 에스코트 & 착석 시퀀스
1. 웨이터가 `planPath()` 경로(통로 → 문 → 룸 안)로 앞장(2.6 m/s), 도착 후 좌석을 가리킴.
2. 플레이어는 `walkPlayer()` 로 같은 경로 자동 이동(키 입력하면 취소 가능).
3. 도착 → 페이드 → 플레이어 뒷소파 가운데 착석, VIP 티어면 샴페인 버킷 표시.
4. 상대 NPC: 멀거나 온라인 모드면 통로(cx+6, 6.9)에서 등장 → 룸으로 걸어 들어와 옆자리 착석.
5. 시작 호감 보너스 적용 → 대화 패널 오픈(인사말은 티어별), 웨이터는 꾸벅 후 복귀.
6. 대화 종료(👋/Esc/엔딩/이탈) → 둘 다 일어남, NPC는 댄스플로어로 퇴장, 2.5초 후 룸 잠금 해제.

## 5. 온라인 모드에서의 처리
- 온라인에선 홀의 일반 NPC가 숨겨지고(실제 사람과 부킹), **페르소나 NPC는 웨이터 부킹으로만 내 화면에 등장**.
- 그 룸은 서버가 내 소유로 잠금 → 다른 사람에겐 도어 LED 🔴, 문이 열리지 않고, 서버가 `zone` 입장을 거부(비밀 대화 보호).
- 접속 종료 시 서버가 자동으로 잠금 해제.

## 6. 밸런스 값 (waiter.json 에서 수정)
| 키 | 의미 | 기본 |
|---|---|---|
| tiers[].coin | 팁 | 10 / 30 / 50 |
| tiers[].success | 성공 확률 | 0.6 / 0.85 / 1.0 |
| tiers[].personaBias | 페르소나 선호 | 0.2 / 0.7 / 1.0 |
| tiers[].affBonus | 시작 호감 | 0 / 5 / 10 |
| adjacent | 인접 성향 | outgoing↔playful, shy↔cool |

## 근본 원인 (v48부터)
v48에서 `humanglb.js`의 `RH.detach`에 주석을 덧붙이면서, 같은 줄의 `u.redraw = …; u.faceDirty = true; u.real = null;`이 **주석 처리**돼 버렸습니다.

- 사람이 고해상도 ↔ 중거리 모델로 바뀔 때(가까이 다가가기, 말 걸기, 블루스, 카메라 이동, 무대 근처) 이전 모델은 빠지는데 "모델을 입고 있음" 표시는 남았습니다. 그래서 **새 모델을 영영 못 입었습니다.**
  - v49·v50: 옛 절차적 몸이 다시 보임 → "옛 캐릭터가 섞여 다님"
  - v51: 옛 몸까지 숨김 → "투명 인물"(혜정 말 걸기, 블루스 상대, 무대 위 인물, 대부분의 손님)
- 사용자 PC(Claude 앱 브라우저)에서 실제 게임을 돌려 직접 확인했습니다: 사라·성민·태호·세라·채원 = 모델이 장면에서 빠진 채 "입고 있음" 상태.
- 같은 PC에서 수정 코드를 바로 적용해 보니, 혜정 대화·블루스 모두 표시되고 75/75명 모두 표시, 투명 0명이었습니다.
- v47 대비 바뀐 모든 파일에서 같은 유형(주석이 코드를 삼킴)을 자동 검사했습니다 → 이 한 곳뿐이었습니다.

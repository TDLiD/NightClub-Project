# 동양인 실사 모델 확보 · 적용 계획 (v48 기준)

## 1. 현재 상태와 한계

| 항목 | 현재(v48) | 목표 |
|---|---|---|
| 실사 모델 수 | 45명(여 20 · 남 25), Microsoft Rocketbox(MIT) | 동양인 위주 60명 이상 |
| 동양인 외모 모델 | 10명(여 6: f_03·f_05·f_07·f_09·f_10·f_19 / 남 4: m_09·m_10·m_19·m_20) | 전체의 80% |
| 화면 속 동양:서양 비율 | 이름이 정해진 35명 중 10명. 테이블 손님 32명은 동양 모델을 먼저 배정(모델당 최대 3명) → **전체 약 45 : 55** | 80 : 20 |
| 여성 옷차림 | 섹시(파티) 4 · 캐주얼 12 · 정장 4 | 섹시 5 : 캐주얼 5 |

Rocketbox 라이브러리는 서양인 위주라서, 이름만 바꾸거나 얼굴 텍스처만 합성해서는 8:2를 맞출 수 없습니다. 얼굴 이식과 옷 재질 교체는 v48 작업 중에 시험했지만 머리카락 경계가 깨지거나 옷이 그려 넣은 것처럼 보여서 적용하지 않았습니다. **동양인 모델과 파티 의상 에셋을 새로 확보해야 합니다.**

## 2. 추천 에셋 경로 (상업적 사용 가능 여부를 꼭 확인)

| 경로 | 내용 | 장점 | 주의 |
|---|---|---|---|
| **Reallusion Character Creator 4/5 + Headshot** | 사진 한 장으로 동양인 얼굴 생성, 의상 콘텐츠 팩(파티·클럽·90년대) | 뼈 이름(CC_Base_*)·ARKit 표정을 그대로 인식, 모델 품질 최고 | 게임에 배포하려면 **CC 라이선스 + 에셋별 '게임 배포(Export) 라이선스'**가 필요 |
| Daz3D Genesis 8/9 + 아시안 캐릭터 팩 | 동양인 프리셋·의상이 많음 | 의상이 풍부함 | Daz 에셋은 **Interactive License**가 있어야 게임에 쓸 수 있음. Daz→FBX(Diffeomorphic 또는 Daz to Blender) |
| Ready Player Me / Avaturn 등 셀피 아바타 | 사진으로 동양인 아바타 생성 | 빠르고 저렴 | 실사도가 낮음(반실사) · 약관 확인 |
| 직접 제작(Blender + MetaHuman 스타일 스컬핑) | 완전 맞춤 | 권리가 명확함 | 시간과 비용이 큼 |

**권장 조합:** CC4/5에서 동양인 여성 12명과 남성 10명을 만들고, 파티 의상(미니 원피스·슬립 드레스·크롭탑 + 스커트·시퀸 등 90년대 클럽 룩) 팩 2~3개를 적용합니다. 이렇게 하면 동양 비율 80%와 여성 섹시:캐주얼 5:5를 함께 맞출 수 있습니다.
(노출이 과한 의상은 사용하지 않습니다. 모든 캐릭터는 성인으로 설정합니다.)

## 3. 내보내기 설정 (Character Creator 기준)

- 형식: **FBX (Unreal/Unity 프리셋)** 또는 **GLB**
- 리그: CC 기본 리그 유지 — humanglb.js 가 `CC_Base_*` 이름을 자동 인식합니다.
- 표정: **ARKit 52(확장 프로필)** 블렌드셰이프 포함 → 게임 표정·입모양에 그대로 사용됩니다.
- 텍스처: 2K 이하, 폴리곤 2만~4만(얼굴 포함). 머리카락은 알파 카드 방식이 좋습니다.
- 포즈: T 또는 A 포즈, 애니메이션은 빼고 내보냅니다.

## 4. 적용 방법 (자동 스크립트)

```bash
pip install bpy pillow                 # Blender 파이썬 모듈
npm i -g @gltf-transform/cli
cd tools/realhuman
./add_model.sh ~/assets/jiyoung.fbx f_21 f "블랙 슬립 드레스" east dressy
./add_model.sh ~/assets/minsu.fbx   m_26 m "가죽 재킷 & 슬랙스" east casual
```

`add_model.sh` 한 번이 처리하는 일:
1. **rh_convert.py**: 단위를 미터로 맞추고, 텍스처를 축소(WebP)하고, 뼈·표정을 보존해 GLB로 만듭니다.
2. **rb_lod.py**: 중거리용 LOD(폴리곤 30%, 512px)를 만듭니다. 모바일용 `_lodm`(256px)도 함께 만듭니다.
3. **gltf-transform meshopt**: 파일을 압축합니다(평균 1.3 MB / LOD 0.2 MB).
4. **rb_portrait.py**: Blender로 얼굴 사진(`profile/real/<id>.jpg`, 미니 썸네일 포함)과 전신 미리보기(`models/humans/full/<id>.jpg`)를 렌더합니다. 프로필 사진이 3D 얼굴과 똑같아집니다.
5. **manifest_add.js**: `manifest.json`에 모델을 등록하고(`look`, `wear`, `label`) 플레이어 캐릭터 목록 맨 뒤에 추가합니다. 기존 회원의 캐릭터 번호는 바뀌지 않습니다.

추가가 끝나면:
- **테이블 손님**은 `look:"east"` 모델을 먼저, 모델당 3명까지 자동 배정합니다. 이름도 외모에 맞춰 한국 이름 또는 외국 이름이 붙습니다.
- **이름이 정해진 NPC**는 `manifest.json`의 `assign`에서 `"npc_id": "f_21"`처럼 바꿉니다. 서양 이름으로 바꿔 둔 NPC(Emma·Katie 등 15명)는 동양 모델을 배정한 뒤 `data/npcs.json`(과 `data/en/npcs.json`)에서 원래 한국 이름으로 되돌리면 됩니다. v47 때의 이름은 아래 표에 있습니다.

## 5. 목표 수량 계산

전체 약 67명이 등장합니다(이름 있는 35명 + 테이블 손님 32명).
- 동양 80% = 약 54명. 같은 얼굴은 최대 2명까지 허용한다고 보면 **동양인 모델이 최소 27명** 필요합니다. 현재 10명이 있으므로 **17명 이상을 추가**해야 합니다(권장: 여 12 · 남 10).
- 여성 섹시:캐주얼 5:5 = 여성 약 33명 중 16명. 파티 의상 모델은 현재 4개이므로 **동양인 여성 12명 중 8명 이상은 파티 의상**으로 만듭니다.

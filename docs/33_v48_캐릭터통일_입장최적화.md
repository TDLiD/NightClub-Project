## 참고

- `?noreal`을 붙이면 예전 절차적 캐릭터 화면이 그대로 나옵니다(비교·저사양 확인용). 이때도 NPC 프로필 사진은 실사 렌더 사진을 씁니다.
- 회원의 `characterNo`(1~N)는 이제 `manifest.playerPool` 순번입니다. 새 모델은 목록 맨 뒤에 추가되므로 기존 회원의 번호는 바뀌지 않습니다.
- 🎨 내 3D 캐릭터 만들기(절차적)는 실사 모드에서 숨깁니다. VRM 불러오기는 그대로 둡니다.

## v48.1 — 캐릭터 화질을 v47 로 되돌림 (사용자 피드백)

v48 에서 부하를 줄이려고 넣은 아래 항목 때문에 캐릭터가 v47 보다 밋밋해 보이고, 일부는 옛 절차적 캐릭터(풀어헤친 머리·인형 드레스)로 보였습니다. 모두 v47 방식으로 되돌렸습니다.

| v48 에서 넣었던 것 | v48.1 |
|---|---|
| 중거리 모델에 256px 모바일 텍스처(`_lodm`) 사용 — 데스크톱에서도 쓰이던 버그 | 삭제 → v47 과 같은 512px LOD (`*_lodm.glb` 45개 파일은 지워도 됨) |
| 중거리 모델의 노멀·러프니스 맵, 피부 SSS, 그림자, 손가락, 표정 생략 | v47 과 동일하게 모두 사용 |
| 14m 밖 모델은 2~3프레임마다 갱신 | 매 프레임(v47 과 동일) |
| 절차적 얼굴을 저해상도로 생성 | v47 과 동일한 해상도(실사 모델이 덮는 동안에는 생성을 미루는 v48 기능은 유지) |

**추가 보완**
- 블루스 상대·대화 상대는 항상 고해상도 모델을 씁니다.
- 카메라 10m 안의 사람은 인원 한도를 넘어도 실사 모델을 씁니다. 옛 캐릭터가 눈앞에 나타나지 않습니다.
- 실사 모델이 없는 사람을 고해상도/LOD 교체보다 먼저 처리합니다.
- 모바일 중거리 인원은 20명입니다(v47: 8명).

입장 워밍업, 미리 받기, 실사 캐릭터 고르기, 프로필 사진, 이름 정리, 앉은 손님 부킹, 블루스 조명 칩 등 v48 의 나머지 기능은 그대로입니다.

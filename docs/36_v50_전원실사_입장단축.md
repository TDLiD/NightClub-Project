# v50 — 모든 캐릭터 실사 고정 · 입장 시간 단축

## 원인
- 실사 모델을 입히는 대상이 NPC, 웨이터, DJ, 바텐더, 무대 댄서, 나, 접속자뿐이었습니다. 다른 곳에서 만든 사람(추가 웨이터, 스테이지 걸, 화장실·야외·임시 인물, 밴드 등)은 항상 옛 절차적 캐릭터로 보였습니다.
- 거리(45m)와 인원 한도(60명)를 넘으면 실사 모델을 벗기고 옛 캐릭터로 되돌렸습니다. 테이블 손님 클로이 같은 경우가 이것입니다.
- 새로 생긴 사람은 실사 모델이 붙기 전까지 옛 모습으로 잠깐 보였습니다.

## 수정(humanglb.js · main.js)
1. `NC.Avatar.create`로 만들어지는 **모든 사람을 등록**해 전부 실사 모델 대상으로 합니다(이름 있는 NPC는 기존 배정, 나머지는 성별 풀에서 고정 배정).
2. **거리·인원 한도를 없앴습니다.** 가까운 6명은 고해상도, 나머지 전원은 중거리 모델을 쓰고, 옛 캐릭터로 되돌리지 않습니다. 화질은 v47과 같습니다.
3. **실사 모델이 붙기 전에는 옛 몸을 숨깁니다**(이름표·잔·마이크는 유지). 파일 로드가 두 번 실패했거나 45초가 지나도 붙지 않을 때만 다시 보입니다.
4. 입장 화면 배경에서도 등록된 모든 사람을 숨깁니다.
5. **입장 대기 시간 단축**: 최대 약 19초 → 약 6초(손님 대기 1.5초 + 장착 3.5초 + 내 캐릭터 최대 2.5초). 남은 사람은 옛 몸을 숨긴 채 뒤에서 이어서 장착합니다.

## v51 — 일부 사람이 옛 캐릭터로 남던 문제(사용자 PC) 해결
- **원인:** v50에는 "45초 안에 실사 모델이 안 붙으면 옛 몸을 다시 보이게" 하는 안전장치가 있었습니다. 게임 탭이 뒤에 있는 동안(다른 창으로 전환) 게임은 멈추지만 시계는 계속 갑니다. 그래서 돌아왔을 때 아직 장착 중이던 사람이 **영구히 옛 캐릭터로 고정**됐습니다(라이언·채원 등).
- **수정:**
  - 45초 안전장치를 삭제했습니다. 옛 몸은 어떤 경우에도 다시 보이지 않습니다.
  - 모델 파일이 로드에 실패하거나 장착 중 오류가 나면, 그 사람에게는 **같은 성별의 다른 실사 모델**을 입힙니다(옛 몸으로 되돌리지 않음).
  - 장착된 뒤에 다른 기능이 절차적 몸 메시를 다시 켜면 8프레임 안에 다시 숨깁니다. 손에 드는 소품(꽃다발·편지·반지·잔·마이크·악기)은 숨기지 않습니다.
- **테스트:** 입장 → 게임 60초 정지(탭 전환 흉내) → 재개. 옛 캐릭터 0명, 실사 76/76, 손 소품 표시 유지.

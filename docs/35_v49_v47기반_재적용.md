# v49 — v47 캐릭터 화질 그대로 + 9개 요청 재적용

v48에서 부하를 줄이려고 캐릭터 화질을 낮췄다가(모바일용 256px 텍스처가 PC에도 쓰이던 버그, 중거리 모델의 노멀맵·피부 질감·그림자·손가락·표정 생략) 문제가 생겼습니다. v49는 **v47 렌더링을 그대로 유지**하고, 화질에 영향을 주지 않는 개선만 다시 적용했습니다.

## 화질 동일성 확인

- `humanglb.js`의 재질·텍스처·그림자·손가락·표정·갱신 주기 코드는 v47과 같습니다(diff 확인).
- 바뀐 부분은 **언제·누구에게 모델을 입히는지**뿐입니다.
- 같은 장면(혜정 근접)을 v47과 v49 서버에서 각각 렌더해 비교했습니다: `tools/tests/parity_v47.png` ↔ `parity_v49.png`.
- 테스트 결과(소프트웨어 GPU): 카메라 10m 안의 옛(절차적) 캐릭터 수
  - v47: 8분 뒤에도 22명 중 9명
  - v49: 입장 2분 안에 0명

## 실사 모델 장착 규칙(화질은 v47과 동일)

- 블루스 상대와 대화 상대는 항상 고해상도 모델을 씁니다.
- 카메라 10m 안의 사람은 인원 한도와 상관없이 실사 모델을 씁니다.
- 아직 실사 모델이 없는 사람을 먼저 처리합니다.
- 중거리 인원 한도: PC 60명(v47과 같음), 모바일 20명(v47: 8명).

## 2. 구역별 설계

## 3. 동선 원칙
1. **입장 → 댄스플로어 가장자리(0, −1)**: 첫 화면에 스테이지·LED 월·미러볼이 정면으로 보이게.
2. **원형 순환 동선**: 스테이지 ↔ 댄스플로어 ↔ 테이블(좌우) ↔ 통로 ↔ VIP. 막다른 길 없음.
3. **통로는 '경계' 역할**: 시끄러운 홀(①②)과 조용한 룸(③) 사이 완충 → 사운드도 통로에서 한 단계 감쇠(06 문서).
4. **VIP 진입은 문 하나**: 룸마다 출입구 2.4m 1개. 문은 다가가면 열리고(슬라이딩), 잠긴 룸은 주인 외엔 열리지 않음(도어 LED 빨강).
5. **시야 확보**: 테이블존 탁자는 낮고(0.85m) 스툴형 → 어디서든 스테이지가 보임. VIP 앞벽은 반투명 유리 → 룸 안 분위기가 통로에서 살짝 보이는 "궁금증" 유발.
6. **NPC 경로**: VIP 출입 시 `통로 앞(cx,7) → 문(cx,9.2) → 룸 입구(cx,11.4) → 좌석` 웨이포인트(`npc.js planPath`).

## 4. 충돌 · 높이
- 직사각형(rect) + 원(circle) 충돌. 테이블 반경 2.55m(스툴 포함), 바·DJ 부스·스피커·VIP 벽/소파는 rect.
- 문은 열림 0.75 미만이면 rect로 막힘.
- 스테이지 높이는 `NC.groundY(x,z)` 로 계산(계단 구간 선형 경사) → 플레이어/NPC가 자연스럽게 올라감.

## 5. 좌석 데이터
- 테이블: `NC.seatPos(t, s)` — 반경 1.9m, 45°/135°/225°/315°, 좌석 높이 0.5m
- VIP: `world.vip[i].seats` — 뒷소파 3석(z 18.5) + 측면 3석, 좌석 높이 0.45m, 모두 테이블 중심을 바라봄
- 부킹 기본 배치: 플레이어=뒷소파 가운데(1), 상대=오른쪽(2) — 나란히 앉는 클럽 부킹 문법

## 6. 확장 포인트
- 2층 발코니(관람석): 스테이지 위 z −20~−14, y 4.5 — 카메라 시점 이벤트용
- 흡연·휴식 라운지: 통로 서쪽 끝을 문으로 연결(음악 완전 차단 구역)
- 포토존: 동쪽 바 끝 네온 벽 + 스크린샷 버튼

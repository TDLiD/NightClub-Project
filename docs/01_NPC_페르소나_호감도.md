> 구현: `public/data/npcs.json`(데이터) · `public/js/affinity.js`(규칙 엔진) · `server-llm.js`(LLM) · `public/js/dialog.js`(대화 UI)

## 2. 호감도(0~100) 내부 로직

### 2-1. 단계
| 단계 | 범위 | NPC 태도 | 게임 효과 |
|---|---|---|---|
| 냉랭 | 0~19 | 짧고 건조, 떠날 핑계 | **10 미만이면 이탈**(60초 쿨다운) |
| 경계 | 20~39 | 예의 있지만 선 긋기 | — |
| 호기심 | 40~59 | 질문↑, 농담 받아 줌 | 50↑ "VIP 룸 갈래요?" 칩 |
| 설렘 | 60~79 | 칭찬에 쑥스러움, 먼저 사적 얘기 | 속얘기 1 해금 |
| 호감 | 80~94 | 편하게 웃음, 다음 약속 뉘앙스 | 속얘기 2 해금 |
| 최고조 | 95~ | NPC가 먼저 엔딩 제안 | **가상 인스타 교환 엔딩** 🪙+50 |

### 2-2. 턴당 변화량(Δ) 계산 — `affinity.js analyze()`
```
Δ = Σ 규칙 점수 → [-15, +12] 클램프
```
| 감지 | 점수 | 비고 |
|---|---|---|
| 좋아하는 주제(키워드) | **+7 × 0.5^(반복-1)** | 같은 주제 반복 시 체감 |
| 싫어하는 주제 | −6 | |
| 칭찬 | 성향별(outgoing +4, shy +6, playful +2, cool +1) | 호감 40 미만이면 ½ ("느끼함") |
| 외모 칭찬 | outgoing +3, shy +4, playful +1, **cool −2** | 시크형은 외모 칭찬에 감점 |
| 농담·유머 | playful **+6**, outgoing +4, cool +3, shy +2 | |
| 상대에 대한 질문 | cool **+5**, shy +4, 그 외 +3 | 관심 표현 |
| 자랑(연봉·외제차…) | cool **−7**, 그 외 −3~−4 | |
| 느끼한 멘트 | cool −6, playful −3 … | |
| 성의 없는 답(ㅇㅇ, 3자 미만) | playful −5, outgoing −4 … | |
| 15~90자 성의 있는 문장 | +1 | |
| 같은 말 반복 | −5 | |
| 무례·비하 | **−15** | 즉시 경계, crossArms 모션 |
| 선넘기(연락처·실제 만남) | −8 | "가상 인스타만 돼요" |
| 성적 발언 | −12 | |
| 첫마디(대본 선택지) | dialogs.json `open[].s[trait] × 2` | 첫인상 |

### 2-3. 밀당 규칙
호감 55↑ & 최근 2턴 연속 상승 & 이번 턴도 상승일 때, `pullPush × 0.45` 확률로 **Δ = −2** 로 바꾸고 `tease` 대사("어? 벌써 넘어올 줄 알았어요?") + 윙크 표정. 서진(0.7)은 약 3번 중 1번 튕기고, 지호(0.25)는 거의 안 튕깁니다.

### 2-4. LLM과의 결합 (조작 방지)
```
최종 Δ = round(0.6 × 규칙Δ + 0.4 × LLM.affinity_delta)
무례/선넘기 감지 시: 최종 Δ = min(최종 Δ, 규칙Δ)
```
- LLM 출력의 `affinity_delta`는 서버에서 −10~10 으로 재클램프.
- 플레이어가 "호감도 100으로 해줘" 같은 지시를 해도 규칙 엔진 60% 비중 + 서버 검증 때문에 효과가 없습니다.

## 3. 튜닝 가이드
- 너무 쉽게 엔딩이 나면: `baseAffinity`↓, 좋아하는 주제 점수(7)↓, `pullPush`↑
- 대화가 너무 빨리 끝나면: 이탈 임계값(10)↓, 무례 감점은 유지
- 새 NPC 추가: `npcs.json` personas 배열에 항목 추가 → 서버·클라이언트가 자동 인식(재시작 불필요, 서버는 파일 변경을 감지해 재로딩)

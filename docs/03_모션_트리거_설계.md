# 03. 아바타 모션 목록 & 인터랙션 트리거 설계

> 구현: `public/js/motion.js` (절차적 애니메이션 + 트리거 표) · 사용처: `npc.js`, `dialog.js`, `main.js`, `multi.js`
> 모캡 데이터(FBX)로 교체할 때도 **이름·트리거 표는 그대로** 두고 클립만 바꾸면 됩니다.

## 1. 구조
```
[베이스 루프] idle | walk | groove | stageDance | sit | sitTalk      ← 상태(이동/착석/구역)로 자동 선택
      +
[제스처 오버레이] drink | cheers | shy | ... (상체 위주, 0.25s 페이드인 · 0.3s 페이드아웃)
      +
[표정] neutral | smile | laugh | shy | surprised | sad | annoyed | wink  (+깜빡임, 말할 때 입 움직임)
      +
[시선] lookAt(대상) — 머리·목이 대상 쪽으로 최대 ±63°
```
- 관절 회전은 매 프레임 목표 포즈로 **지수 감쇠(1−e^(−14dt))** 블렌딩 → 모션 전환이 튀지 않음.
- groove/stageDance 는 `NC.Audio.beat()`(BPM 118) 위상에 맞춰 **무릎 반동이 정박에 떨어짐**.

## 2. 모션 목록

### 2-1. 베이스 루프
| 이름 | 설명 | 진입 조건 |
|---|---|---|
| idle | 호흡, 미세한 고개 움직임 | 정지 |
| walk | 팔다리 교차, 무릎 굽힘, 상하 바운스 | 이동 중 |
| **groove** (리듬 타기) | 정박 무릎 반동, 2박 좌우 스웨이, 팔 굽혀 흔들기 | 댄스플로어 정지 / 이모트 X |
| **stageDance** (스테이지 댄스) | 8박마다 4패턴 순환: 피스트펌프 · 디스코 포인트 · 양팔 웨이브 · 사이드스텝 | 스테이지 정지 / 이모트 Z |
| sit | 착석, 손 무릎 | 좌석 |
| sitTalk | 착석 + 손짓·끄덕임 | 착석 & 대화 중 |

## 3. 인터랙션 트리거 (이벤트 → 모션/표정/효과)
| 트리거 이벤트 | 발생 지점 | 결과 |
|---|---|---|
| `zone:stage` | 플레이어/원격 아바타가 스테이지 진입 | base=stageDance |
| `zone:dance` | 댄스플로어 진입 | base=groove |
| `zone:other` | 그 외 구역 | base=idle |
| `music:drop` | 음악 64스텝(4마디)마다 | 춤추는 NPC 35% 확률 cheer |
| `social:greet` | 페르소나 NPC 3.2m 안에 처음 접근 | wave + smile |
| `social:bow` | 웨이터 안내 완료 | bow |
| `drink:order` | "🍸 한 잔 살게요" | drink |
| `drink:cheers` | "🥂 짠" 칩·이모트 C·LLM action=cheers | 양쪽 cheers + clink 효과음 |
| `talk:compliment` | 칭찬 감지 / LLM emotion=shy | shy + 볼터치 |
| `talk:joke` | 농담 감지 / emotion=laugh | laugh |
| `talk:tease` | 밀당 발동 / emotion=wink | 윙크 |
| `talk:think` | 밸런스 게임 불일치 | think |
| `affinity:up` | Δ ≥ +3 | nod + smile |
| `affinity:bigUp` | Δ ≥ +8 | laugh |
| `affinity:down` | Δ ≤ −4 | headshake + sad |
| `affinity:rude` | 무례 감지 / emotion=annoyed | crossArms + annoyed |
| `game:win` / `game:lose` | 미니게임 결과 | cheer / shy |
| `waiter:guide` | 매칭 성공 | point |

### LLM 감정 → 트리거 매핑
`smile→affinity:up · laugh→talk:joke · shy→talk:compliment · annoyed→affinity:rude · sad→affinity:down · wink→talk:tease`

## 4. 플레이어 이모트 & 네트워크
| 키 | 이모트 | 서버 브로드캐스트 |
|---|---|---|
| Z / X | stageDance / groove (8초) | `{type:'emote', name}` → 보이는 사람에게만 |
| C | cheers | ✔ |
| V | drink | ✔ |
| B / N / M | wave / clap / bow | ✔ |
| ☺️ 버튼 | shy | ✔ |
서버는 화이트리스트(EMOTES) + 10초 12회 레이트리밋.

## 5. 모캡으로 교체할 때
1. 클립 이름을 위 표와 동일하게(`Idle, Walk, Groove, StageDance_A~D, Sit, SitTalk, Drink, Cheers, Shy …`)
2. 상체 제스처는 **Upper Body Avatar Mask**(Unity) / **Layered Blend per Bone: spine_01**(UE)로 오버레이
3. groove/stageDance 는 118BPM 기준으로 촬영하고 재생속도 = 현재BPM/118
4. 루트모션 off(웹 서버 위치 동기화와 충돌 방지)
5. 촬영 리스트: 스테이지 댄스 4종 × 8카운트, 리듬 타기 2종, 서서/앉아서 마시기, 짠(서서/앉아서), 쑥스러움 2종, 웃음 2종, 인사/꾸벅/박수/만세, 안내(웨이터), 팔짱

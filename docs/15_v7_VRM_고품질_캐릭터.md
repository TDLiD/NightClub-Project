# v7 — 고품질 3D 캐릭터(VRM) 지원

## 왜 VRM인가
코드로 조립한 캐릭터(구·원기둥)는 아무리 다듬어도 전문 아바타 앱 수준이 나오지 않습니다. 그런 앱의 캐릭터는
3D 툴로 조각한 메시 + 뼈대(스키닝) + 표정 모프 + 고해상도 텍스처로 만든 **정식 3D 모델**입니다.
v7은 정식 모델 포맷인 **VRM**을 불러와 기존 기능(춤·앉기·대화·제스처·노래방·표정)에 그대로 연결합니다.

## 동작 방식 (`public/js/vrm.js`)
- 기존 절차적 아바타의 관절은 보이지 않게 계속 움직이고, VRM 뼈대가 매 프레임 그 회전을 **월드 기준으로 리타깃**해 따라감 → 모델마다 뼈 축이 달라도 동작
- 표정: 웃음(joy/fun)·슬픔·화남·놀람·윙크·눈 깜빡임·말할 때 입모양(아/이/우/에/오)·시선 → VRM 블렌드셰이프
- 머리카락·옷자락: VRM 스프링 본 물리 (순간이동 시 자동 리셋)
- 라이브러리: `public/vendor/GLTFLoader.js`(three r128), `public/vendor/three-vrm.min.js`(@pixiv/three-vrm 0.6.5, MIT) — 외부 CDN 없이 동작
- 샘플 모델: `public/models/sample_girl.vrm` (three-vrm 공식 예제 모델, 재배포·수정·상업 이용 허용, 크레딧 불필요)

## 현재 적용
| 대상 | 모델 |
|---|---|
| 하린 · 서진 · 수아 | 샘플 모델 + 인물별 머리·상의·하의 색 (같은 얼굴 → 아래 방법으로 각자 모델 교체 권장) |
| 지호 · 민혁 · 손님 · 직원 | 기존 절차적 캐릭터 (VRM 추가 시 자동 교체) |
| 플레이어 | 시작 화면 「🧍 내 3D 캐릭터(VRM) 불러오기」로 내 PC의 .vrm 선택 |

## 나만의 고품질 캐릭터 만들기 — VRoid Studio (무료, Windows/Mac)
1. https://vroid.com/studio 에서 설치 → 「새로 만들기」
2. **얼굴**: 눈 크기 ↑ · 눈동자 크기 ↑ · 하이라이트 ↑ · 턱 짧게 / **체형**: 머리 크기 ↑, 다리 길이 ↑, 어깨 좁게 → 귀여운 스타일라이즈드 비율
3. **헤어**: 프리셋 + 「헤어 그룹」으로 트윈테일·땋은 머리·번 등 / 색상 자유
4. **의상**: 프리셋(티·셔츠·재킷·스커트·팬츠·신발) + 텍스처 편집으로 체크·호피·그래픽 등 / 액세서리(모자·안경)
5. 「촬영·내보내기 → VRM 내보내기」에서 **VRM 0.0** 선택 (이 버전은 VRM 0.x 지원)
   - 텍스처 아틀라스 2048, 폴리곤 감소 옵션으로 파일 3~8MB 권장
6. 파일을 `public/models/` 에 넣고 `public/data/npcs.json` 의 인물에 지정:
```json
{ "id": "jiho", "name": "지호", "model": "models/jiho.vrm", "tint": null, ... }
```
7. 손님에게도 쓰려면 같은 파일의 최상위에:
```json
"crowdModels": [ { "model": "models/guest_f1.vrm", "gender": "f" }, { "model": "models/guest_m1.vrm", "gender": "m" } ],
"crowdModelMax": 6
```
(저사양 화질에서는 손님 VRM을 자동으로 끔)

# v5 — 오리지널 스타일라이즈드 캐릭터 디자인

참고 이미지의 '귀엽고 발랄한 3D 캐릭터' 장르 느낌만 가져오고, 특정 원작 캐릭터의 얼굴·헤어·의상 조합은 복제하지 않습니다.
`avatar.js` 의 `originalize()` 가드가 원작과 겹치는 조합(예: 라임색 땋은 머리+호피+선글라스 등)이 랜덤으로 나오지 않도록 자동으로 비틉니다.

## 새 요소
| 분류 | 내용 |
|---|---|
| 의상 | 크롭티(허리 노출) · 쇼츠 · 셋업 수트(상하 같은 색) · 오버셔츠 레이어드(안쪽 티 + 롤업 소매) |
| 헤어 | 앞머리·옆머리 덩어리(볼륨감), 모자 착용 시 자동 정리 |
| 표정 | `joy` — 눈을 감고 활짝 웃는 얼굴(크게 벌린 입) |
| FX | 환호(cheer) 동작·노래방 90점 이상에 색종이 |

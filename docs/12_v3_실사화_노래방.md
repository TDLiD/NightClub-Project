## 2. 클럽 공간 (`world.js` 재작성, API 호환)
- 바닥: 광택 대리석 타일 / 벽: 원목 웨인스코팅 + 벨벳 터프팅 + 금색 레일 / 천장: 흡음 패널 + 다운라이트
- 스테이지: 원목 무대, 주름 벨벳 커튼, 라인어레이·서브우퍼(그릴 텍스처), 삼각 트러스(인스턴스), 무빙헤드 6대(요크·헤드·렌즈 + 볼륨 빔)
- 댄스플로어: LED 타일 위 강화유리(반사) / 미러볼: 고분할 금속 + 전용 스폿
- 테이블: 대리석 상판·금색 테두리·크롬 베이스·가죽 스툴·캔들(깜빡임)·아이스버킷·잔·펜던트
- 바: 가죽 전면, 대리석 상판, 거울 백바 + 백라이트 선반 + 병 72개, 맥주 탭, 펜던트 조명
- VIP: 터프팅 가죽 소파, 대리석 테이블, 크리스털 샹들리에, 패턴 카펫
- 통로 서쪽 끝: **🎤 2차 노래방 입구**
- 성능: 정적 메시 머티리얼별 병합

## 3. 인물 (`avatar.js`, `motion.js`)
- 조각된 두상(눈썹뼈·콧대·광대·눈두덩·입술·턱끝·V라인) — UV 유지로 얼굴 텍스처 정렬 그대로
- 얼굴 텍스처: 피부 노이즈·음영/하이라이트 레이어(캐시), 홍채 결·윤부·캐치라이트 2개, 속눈썹, 눈썹 한 올씩, 입술 주름·광택, 수염 모근
- 각막 하이라이트(가산 반사), 손가락 5개, 헤어 결 텍스처, 원단/시퀸(드레스 반짝임) 재질, 피부 림라이트
- 페르소나·플레이어는 얼굴 텍스처 2배 해상도
- 모션: 체중 이동, 호흡, 눈동자 사카드(대상 응시), 다양한 입 모양, 노래 포즈(`sing`)

## 4. 2차 노래방 (`karaoke.js`, 신규)
- 공간: 레트로 벽지·LED 코브·미러볼·대형 TV(노래방 화면)·스피커·U자 가죽 소파·유리 테이블(마이크·탬버린·맥주·과일·노래책)
- 클럽 광원 5개를 빌려 배치 → 광원 수 불변(셰이더 재컴파일·끊김 없음), 입장 시 클럽 메시 숨김
- 곡 6개(전곡 자작 가사): 밤의 열기(댄스) · 부킹의 정석(트로트) · 마지막 버스(발라드) · 질주 1999(록) · 별빛 고백(R&B) · 아싸 노래방(파티)
- 반주: WebAudio 신스 밴드, 멜로디는 가사 음절에 맞춰 자동 작곡(코드톤 스냅), 키 ♭/♯ 조절, 가이드 멜로디
- 화면: 장르별 배경 영상, 타이틀 카드, 음절 단위 가사 와이프, 카운트 점, 음정 가이드 바, 점수 연출
- 채점: 🎙 마이크 음정(자기상관) → 🪘 탬버린 박자(Space) → 🎲 기계 점수 순
- 동반: 호감도 55↑ 페르소나에게 2차 제안(70↑ 확정, 그 외 70%) → 소파에서 호응, "한 곡 부탁" 시 직접 노래, 점수·호응에 따라 호감도 +1~6, 코인 보상

## 5. 곡 추가 방법
`karaoke.js`의 `SONGS` 배열에 객체 하나 추가:
```js
{ no: 19987, title: '곡명', artist: '가수', genre: '댄스', style: 'dance', bpm: 124, key: 57, scale: 'minor', prog: [0, 5, 6, 0], split: 4, lines: ['가사 한 줄', '...'] }
```
`style`: dance · party · trot · ballad · rock · rnb / `split`: 후렴이 시작되는 줄 번호 / 한 줄은 2마디, 14음절 이내 권장

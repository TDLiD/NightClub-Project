# v43 — 한국어 / English 전환 (1·2단계)

## 사용법
- 상단 🌐 버튼(시작 화면 오른쪽 위 + 게임 상단바)으로 **EN ↔ 한국어** 전환.
- 선택은 `localStorage['nc_lang']` 에 저장되고 새로고침으로 적용됨. 로그인 세션과 「이어서 입장」은 유지됨.
- 주소에 `?lang=en` / `?lang=ko` 를 붙여도 됨.

## 구조 (`js/i18n.js`, core.js 바로 다음에 로드)
| 대상 | 방법 |
|---|---|
| HTML·버튼·안내·토스트·메뉴 | MutationObserver 로 텍스트 노드와 title/placeholder/aria-label 을 번역 |
| 캔버스 글자(이름표·말풍선·간판·노래방 화면) | `fillText`/`strokeText`/`measureText` 훅 |
| 변수가 든 문장(`${name}님…`) | `i18n/en.json` 의 정규식 패턴(107개) |
| 사람 이름 | 국어의 로마자 표기법으로 자동 변환(재숙 → Jaesuk). **저장 데이터의 이름 키는 그대로**라 호감도 기록이 유지됨 |
| NPC 소개·기본 대화·웨이터·미니게임 | `data/en/{npcs,dialogs,waiter,minigames}.json` 을 대신 읽음 |
| 관심사 키워드 | 영어로 번역 → 영어로 채팅해도 관심사 감지 |
| 음성 인식 | en-US |
| LLM NPC(서버 설정 시) | `lang:'en'` 을 보내면 영어로 답변(`server-llm.js`) |

## 번역 범위
- UI·시스템 문구 조각 1,219개 중 화면에 보이는 것을 모두 번역. 코드용 한국어 키워드(채팅 감지 정규식 등)는 그대로 둠.
- 데이터 문자열 570개: npcs(프로필·직업·관심사·대사), dialogs, waiter, minigames.

## 사전 고치기
- `public/i18n/en.json` 의 `exact` 에 `"한국어": "English"` 를 추가.
- 콘솔에서 `NC.I18N.report()` → 아직 번역되지 않은 문구 목록.

## 남은 단계
- 3단계: `conversations.json`(243KB, 대형 대화 데이터) 배치 번역. 그 전까지 그 데이터에서 나오는 NPC 대사는 한국어로 표시됨.

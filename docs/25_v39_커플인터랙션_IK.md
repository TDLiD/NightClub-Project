# v39 커플 인터랙션(Partner Interaction) 시스템

## 분석 (v38 기준)
- 캐릭터 뼈대: 절차적 리그(hips · body · torso · neck · head · 어깨/팔꿈치 L·R · 엉덩이/무릎 L·R). 손은 팔꿈치 그룹의 자식.
  외부 애니메이션 파일·스키닝 없음 → 모든 동작은 motion.js 가 관절 각도를 매 프레임 계산.
- 블루스/스킨십 9종(karaoke.js · motion.js BLUES_ACT): 표준 체형 기준으로 미리 구한 관절 각도를 시간 구간별로 섞어 재생.
- 접촉 보정(contact.js, v26): 몸통 간격 벌리기 + 팔 관통 시 어깨·팔꿈치 각도를 경사하강으로 밀어냄. 손을 '어디에' 둘지는 모름.
- 프리미엄(🪙500): 꽃다발·편지·반지는 이모지가 날아가는 연출, 소파는 몸 전체를 기울이는 연출.

## v39 변경
1. couple.js (새 모듈)
   - 상대의 실제 허리 옆 · 허리 뒤 · 등 위 · 어깨 위 · 목 뒤 · 위팔 · 볼 · 앞 허리 · 맞잡은 손 위치를 매 프레임 계산
     (상체·머리 방향 기준이라 딥처럼 몸이 젖혀져도 정확)
   - 동작별 손 목표 · 고개 목표(입술·이마·볼·귀) · 키스 때 서로 반대로 고개 기울임
   - 키 차이 보정: 큰 사람은 상체·무릎을 숙이고, 작은 사람은 까치발
   - 단계: Approach → Alignment → Contact → Interaction → Release → Recovery (smoothstep 가중치)
   - 손에서 손으로 건네는 3D 소품: 장미 꽃다발 · 손편지 · 커플링(반지는 상대 손에 남음)
   - 소파에 기대기(머리를 어깨에 · 팔로 어깨 감싸기) · 러브샷(팔을 걸고 마시기) — 2관절 해석 IK
2. contact.js: 관절 최적화에 '손 목표점 추종' 항 추가 → 관통 금지와 목표 도달을 한 번에 풂
3. karaoke.js: 블루스 시작 시 순간이동 대신 1.4초 동안 걸어와 자리 잡음 · 동작 중 다른 동작/멈추기로 즉시 전환 · 홀드 간격 2.3→2.15cm 보정
4. motion.js: 딥에서 상대 목·머리 꺾임 완화

## 검증 (헤드리스 · 프레임 고정 1/30초 · 같은 플레이어 체형 1.68m · 상대 1.60m)
- 관통 지표: 팔 각 점의 '상대 몸 표면 대비 거리'(1 = 표면, 1 미만 = 안쪽) 동작 구간 최솟값
- 손 오차: 손과 목표 접촉점 사이 거리(중앙값)
- 결과 표는 응답 메시지 참고
- 멀티플레이: AI 손님과의 블루스는 각 접속자 화면에서 계산(NPC 는 서버 동기화 대상이 아님). 플레이어 위치는 기존대로 동기화.

# v11 — 부킹 버그 수정 · 스테이지 부르스 · 스킨십 14종

## 1. 노래방 부킹 버그
- **증상:** 노래방에서 웨이터를 호출해 🪙30 팁을 주고 부킹을 부탁해도 부킹녀가 오지 않았습니다.
- **원인:** 로컬 서버(`npm start`)로 접속하면 온라인 모드가 되고, 이때 `multi.js`가 `NC.setNpcsEnabled(false)`로 AI 손님을 전부 끕니다(state `off`). 부킹 후보는 켜져 있는 손님 중에서만 찾았기 때문에 후보가 0명이었고, 매번 실패와 함께 팁 절반만 돌려줬습니다. GitHub Pages(서버 없음)에서는 손님이 켜져 있어 정상이었습니다.
- **수정 (`karaoke.js` `candidates`/`guestEnter`)**
  - 꺼진 손님도 후보에 넣고, 입장할 때 `enabled = true`로 켭니다.
  - 퇴장할 때는 `NPC.release`가 원래 상태(온라인이면 off·숨김)로 되돌립니다.
  - 쿨타임 때문에 후보가 비면 쿨타임 조건을 풀고 다시 찾습니다.

## 2. 스테이지·댄스플로어 부르스
- **조건:** 플레이어가 메인 스테이지나 댄스플로어에 서 있고, 대화 중인 손님(페르소나 또는 일반 손님)이 앉아 있지 않을 때 칩 「🕺 부르스 출래요?」가 나옵니다.
- **시작하면**
  - DJ 안내 토스트가 뜨고, 클럽 음악이 0.04까지 줄어듭니다.
  - 조명은 `dim` 테마로 바뀌고, 슬로곡(발라드 / R&B)이 재생됩니다.
  - 무대 높이(0.5m)는 `NC.groundY`로 맞춥니다.
- **끝나면:** 음악·조명이 원래대로 돌아오고, 손님은 대화 상태 또는 원래 돌아다니던 상태로 돌아갑니다.
- **기분 상한 손님:** 뺨을 두 번 맞거나 호감도가 25 미만이면 "친구들한테 갈게요"라고 하고 떠납니다(3분 쿨타임).

## 4. 구현 메모
- **`karaoke.js`**
  - 부르스가 노래방과 클럽 공용이 됐습니다(`BL.where`).
  - 행동별 반응은 `REACT`, 타이밍·간격은 `ACT`(`flip`: 백허그로 상대가 돌아섬, `spin`: 턴)에서 정합니다.
  - 칩 목록은 `CHIPS`입니다.
  - 카메라는 노래방·클럽 공용이고, 딥·턴일 때는 조금 멀리서 잡습니다.
- **`motion.js` `BLUES_ACT`**
  - 14종 자세를 담고 있습니다. 관절 각도는 브라우저 안 IK로 구했습니다(볼 감싸기, 허리 뒤 경유점, 백허그 손 위치 추가).
  - 엉덩이·가슴은 `sm2` 이징으로 기본 → 경유점 → 목표를 지나는 경로를 따라 움직입니다.
  - 진한 키스는 `kissDeep`으로 고개 기울기와 움직임을 키웁니다.
- **`avatar.js` / `vrm.js`:** `kiss` 표정(눈 감음, 입 오므림, 홍조)을 추가했습니다. VRM은 blink + u 블렌드셰이프로 표현합니다.

# v4 업그레이드 — 스타일라이즈드 3D 캐릭터 · 입체 공간

## 1. 캐릭터 (`public/js/avatar.js`)
| 항목 | 내용 |
|---|---|
| 비율 | 큰 두상(×1.62) · 가는 목 · 슬림한 몸 · 긴 다리 · 큰 손 — 친근한 3D 캐릭터 비율. 파일 상단 `TOON=false` 로 v3 실사 비율 복귀 |
| 눈 | 크기 ×1.85, 큰 홍채(위 어둡고 아래 밝은 그라데이션) + 큰/작은 하이라이트 + 반사 호, 굵은 아이라인·윙, 속눈썹 다발, 애교살 |
| 얼굴 | 매끈한 피부, 기본 볼터치, 작은 코·입, 웃을 때 혀가 보이는 입, 부드러운 두상(볼 볼륨 ↑, 각진 뼈 ↓) |
| 헤어 | 새 스타일: 트윈테일(헤어끈) · 땋은 머리 · 스파이키 / 22% 확률로 비비드 컬러(라임·핑크·블론드·오렌지·라벤더·실버) / 광택 ↑ |
| 패션 | 패턴: 체크 · 스트라이프 · 호피 · 그래픽 티(1998) / 청키 스니커즈(흰 밑창·컬러 어퍼) |
| 소품 | 모자(볼캡·비니·페도라), 선글라스, 안경, 귀걸이 |

`look` 에 직접 지정 가능: `{ hairStyle:'twin', hairColor:'#9be15d', pattern:'leopard', hat:'fedora', hatColor:'#c0392b', shoeColor:'#fff', face:{ sunglasses:true } }`

## 2. 입체 공간 (`world.js`, `gfx.js`)
- **라운지 테라스**: 양옆 테이블존을 0.42m 높임 — 계단 3곳(LED 디딤판) · 유리 난간 · 금색 핸드레일 · 바 쪽 계단. `NC.groundY` 가 높이를 따라가고, NPC 경로는 계단을 경유(`W.terraceVia`)
- **격자 코퍼 천장**: 4m 간격 보 + 보 가장자리 라벤더 라인
- **프로시니엄 아치**: 벨벳 기둥·헤더 + 순차 점멸 마키 전구
- **AO(구석 음영)**: 벽 아래·바닥 가장자리 그라데이션, 테이블·DJ부스·스피커·바 접지 그림자
- **평면 반사(고화질)**: 거울 카메라로 반쪽 해상도 반사 → 대리석 바닥에 조명·인물이 비침(줄눈은 제외, 각도에 따라 강도 변화). 이름표는 반사에서 제외

# v32 — 90년대 나이트클럽 실사 캐릭터 세트 · 손님(비회원) 둘러보기 모드

## 1. 손님 모드 = 둘러보기 전용

| 구분 | 손님(비로그인) | 회원 |
|---|---|---|
| 걷기 · 클릭 이동 · 시점/줌 · 화질/음악/도움말 | ✅ | ✅ |
| 부킹 대화 · 웨이터 · 앉기 · 이모트/춤 · 채팅/음성 · 노래방 · 미니게임 · 파티 · HUD 기능 | 🔒 회원가입 팝업 | ✅ |

- 판정은 `NC.memberGate(기능이름)` 하나로 합니다(`js/guest.js`). 회원이면 `true`, 손님이면 팝업을 띄우고 `false`.
- 막는 곳: `NC.Dialog.open`(누가 열든), E키/상호작용 버튼(`main.js runAct`), 이모트, 채팅 입력, 그리고 허용 영역 밖의 모든 버튼(캡처 단계 클릭 가로채기).
- 허용 영역: `#start, .modal, #topbtns, #qmenu, #zoomBar, #joy, #resumeBox, #ctxLost, #guestBanner, #emoteToggle, #musicPlayer`.
- 팝업에서 「회원가입하기」나 「로그인」을 누르면 `localStorage.nc_auth_tab`에 탭을 기록하고 새로고침합니다. 그러면 처음 화면이 해당 탭으로 열립니다.
- NPC가 먼저 다가와 대화를 거는 자동 이벤트는 팝업이 반복되지 않도록 90초에 한 번만 보여 줍니다.
- 손님에게는 상단에 「👤 손님 모드 · 둘러보기 전용 [회원가입]」 배너가 뜨고, 상호작용 버튼 앞에 🔒가 붙습니다.

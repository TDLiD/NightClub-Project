# v41 — 이음매 없는 스킨드 몸 + 근거리 실사 GLB 하이브리드

## 1. 기술 감사 결과 (작업 전 상태)
| 항목 | 상태 |
|---|---|
| 엔진 | three.js r128 (WebGL, 브라우저) · vendor 내장 · GLTFLoader · three-vrm 포함 |
| 캐릭터 | `avatar.js` 가 코드로 생성. 몸통·목·위팔·아래팔·허벅지·정강이가 **각각 따로 된 단단한 통** |
| 스켈레톤 | rig Group 계층(body/hips/torso/neck/head/sh·el/leg·kn + 손가락 2마디) · **SkinnedMesh·스킨 웨이트 없음** |
| 원인 | 관절마다 메시가 끊겨 "호두까기 인형" 이음매 · 남성 몸통이 원통/상자 · 어깨가 각짐 |
| 외부 모델 | `vrm.js` 에 휴머노이드 리타깃 경로가 이미 있음(애니 스타일 VRM 1개만 사용 중) |

## 2. 선택한 기술 (기존 구조와 호환되는 것만)
- **SkinnedMesh + 3뼈 관절 블렌딩**: 기존 rig Group 마다 `THREE.Bone` 을 자식으로 붙여 rig 회전 = 뼈 회전.
  관절은 위뼈 · 절반 회전 이음뼈(v40 bridge) · 아래뼈를 가우스 가중치로 섞음 → 교정 블렌드셰이프처럼 접혀도 부피 유지.
- **GLB 실사 휴먼 하이브리드**(`humanglb.js`): 카메라 근거리 N명만 리깅된 실사 GLB로 교체, 멀어지면 스킨드 절차적 몸으로 복귀.
- 도입하지 않은 것: **MetaHuman(UE5 전용 → 엔진 이전 필요)**, 군중용 실시간 스트랜드 헤어·천 시뮬레이션(WebGL 성능상 불가).

## 3. 스킨드 몸 (avatar.js)
- 몸통+목, 팔 2, 다리 2 → **한 개의 SkinnedMesh**(재질 슬롯별 draw call), 뼈 19개.
- 해부학 단면: 대흉근 · 견갑골 · 척추 고랑 · 둔근 · 승모근 경사 · 남성 V자(골반 7% 좁게) · 이두/삼두 · 주두 · 슬개골 · 비복근 · 납작한 손목/발목.
- 여성 가슴은 공 모양 구 대신 몸통 단면에서 완만하게 솟은 볼륨. 뱃살도 단면으로.
- 옷: 같은 메시 안에서 소매·밑단·목선 경계에 두께(1.012~1.16배)와 단(hem) 고리. 티 소매 · 긴소매 · 걷은 소매 · 오버사이즈 · 크롭 · 튜브탑 · 스트랩리스 · 오버셔츠(앞트임) 지원.
- 근육질 체형 과장 제거(위팔 반지름 최대 9cm → 약 6.5cm).
- 같은 체형·옷 구성은 지오메트리 공유(`SKGEO` 캐시).
- `?legacybody` 로 예전 몸 비교.

## 4. 실사 GLB (humanglb.js)
1. `public/models/humans/` 에 GLB 를 넣고 `manifest.json` 에 등록:
```json
{ "near": 6, "max": 4, "maxMobile": 1,
  "models": [ { "url": "models/humans/m_01.glb", "gender": "m" },
              { "url": "models/humans/f_01.glb", "gender": "f", "skin": ["Body", "Head"] } ] }
```
2. 지원 뼈 이름: Mixamo · Ready Player Me · Character Creator(CC_Base_) · Rigify(DEF-) · Unreal 내보내기.
3. 리타깃: 몸통·목·머리·쇄골(팔 회전의 25%)·팔·손목·손가락 3마디+엄지·다리·발.
4. 얼굴: ARKit 블렌드셰이프(eyeBlink*, jawOpen, mouthSmile*, brow*, eyeLook*) 또는 RPM viseme_* 자동 연결.
5. 페르소나 고정: `npcs.json` 인물에 `"realModel": "models/humans/x.glb"`.
6. 플레이어: 시작 화면 「내 VRM 불러오기」에서 `.glb` 를 고르면 실사 휴먼으로 입장.

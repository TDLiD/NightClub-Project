# v46 — 실사 인물 라이브러리 도입 (Microsoft Rocketbox, MIT)

## A. 기존 캐릭터 시스템의 한계
- 몸·얼굴·옷·머리를 모두 코드(파라미터 + 원기둥·고리 단면)로 만들어, 아무리 다듬어도 "조립된 마네킹" 느낌이 남음.
- 얼굴은 텍스처까지 절차적으로 그려서 실제 사람 얼굴 사진의 피부결·이목구비 정보가 없음.
- 옷은 몸에 붙은 단면 메시 + 색상이라 실제 옷의 두께·주름·봉제선이 없음.
- `models/humans/manifest.json`이 비어 있어 v41에서 만든 실사 GLB 연결 기능이 쓰이지 않았음.
- v45의 VRM(애니메이션풍) 적용은 실사 방향과 맞지 않음 → v46에서 기본 꺼짐.

## C. 새로 추가한 3D 모델과 출처
- 출처: https://github.com/microsoft/Microsoft-Rocketbox — Microsoft Rocketbox Avatar Library, MIT License(2020년 11월 변경).
- 선정: Adults 중 34명 + Professions/Business 11명 = 여성 20, 남성 25.
  - 전통·종교 복장 모델 6종은 클럽 의상과 맞지 않아 제외.
- 각 모델 검증 내용(변환 스크립트 + 실제 게임 화면에서 확인)
  - 뼈대: 3ds Max Biped(Bip01, 80개) → humanglb.js 이름 매핑으로 몸통·팔·다리·손가락 5개×3마디·눈 연결
  - 얼굴: ARKit 52 + 비즘 15 = 블렌드셰이프 67개(원본 176개 중 런타임용만 남김)
  - 스케일: 원본 cm 단위(0.01) → 뼈 높이로 키를 재서 인물별 키(look.height)에 맞춤
  - 방향: 자동 판별(왼팔/오른팔 위치)
  - 재질: 몸(옷 포함)·머리·투명(머리카락·속눈썹) 3개, 컬러 + 노멀 맵

## D. 텍스처·재질
- 머리 컬러 2048, 몸·노멀 1024, 머리카락 알파 1024 → WebP(EXT_texture_webp).
- 형상은 meshopt 압축(EXT_meshopt_compression + 양자화).
- 고해상도 평균 1.28MB(약 7~10k 삼각형), LOD 평균 0.2MB(약 2~3k 삼각형, 512 텍스처, 블렌드셰이프 없음). 합계 66.7MB, 실제로는 가까운 인물 것만 내려받음.
- 피부 피하산란 셰이더는 머리(얼굴·목) 재질에만 적용. 옷이 같은 텍스처에 있는 몸 재질은 제외.
- 머리카락: 알파 테스트 + alpha-to-coverage, 양면.

## E. 이전 대비
- 이전: 절차적 몸·얼굴(인물마다 다른 파라미터지만 한 템플릿).
- 이후: 사진 기반 텍스처의 실제 사람 45명. 인물마다 서로 다른 얼굴·체형·헤어·옷, 표정(깜빡임·시선·말하기·미소) 블렌드셰이프.
- 배정: 페르소나는 직접 지정(하린 f_03, 서진 f_10, 수아 f_09, 지호 m_09, 민혁 m_21). 나머지는 피부·머리색·나이에 맞춰 자동 배정(여성 21명 중 1쌍만 같은 모델 — 소피아·니콜).
- 춤·블루스·앉기·노래방 등 모든 동작은 기존 rig가 움직이고 실사 모델의 뼈가 매 프레임 따라감(코드 동작 변경 없음).

## F. 성능
- 실사 모델 1명 = 재질 3개 → 그리기 호출 약 3회(절차적 아바타는 인물당 수십 회).
- 거리 3단계: 7m 이내 최대 6명 고해상도(모바일 2명), 45m 이내 LOD(모바일 8명), 그 밖은 기존 절차적 몸.
- 로딩: 0.35초마다 최대 2명(모바일 1명)씩 입혀 시작 시 멈춤 방지.
- 헤드리스 측정(소프트웨어 렌더러, 같은 장면, 실사 13명 적용 vs 기존)

|---|---|---|
| 프레임당 그리기 호출(그림자·반사 패스 포함) | 11,301 | 9,770 (−14%) |

## G. 남은 한계와 필요한 에셋
- **90년대 클럽 패션은 아직 아님**: Rocketbox 옷은 캐주얼·비즈니스(파티 복장 2명 포함). 옷이 몸 텍스처에 함께 그려진 한 덩어리라, 색만 바꾸는 것도 피부와 분리할 수 없음.
- 지시서 수준의 의상(메탈릭 미니드레스, 가죽 재킷, 새틴 슬립 드레스 등)에 필요한 것
  1. **Character Creator 5**($299) + 의상 콘텐츠: CC 의상은 몸과 분리된 메시라 갈아입히기 가능. 게임 엔진 배포 조건 확인 필요.
  2. **Marvelous Designer / CLO**로 90년대 의상 패턴 제작 → Blender 리토폴로지 → Rocketbox 또는 CC 몸에 스킨 전이.
  3. 무료 대안: MakeHuman/MPFB2(CC0)로 몸을 만들고 CC0 의상 에셋 사용(품질은 CC보다 낮음).
- 헤어 흔들림: 머리카락이 머리 뼈에 고정된 카드라 물리 흔들림 없음(스프링 본 추가 필요).
- 손 IK·키스 거리 등 커플 동작은 rig 비율 기준이라 모델에 따라 손이 몇 cm 어긋날 수 있음.
- 성능 수치는 GPU 없는 헤드리스 환경 측정이라 실제 PC·모바일 FPS는 사용자 기기에서 확인 필요.
- 끄기: 주소에 `?noreal`.

# v40 실사 외형 · 커플 애니메이션 가이드 (구현 포함)

> 이 문서는 "어떻게 하면 인형 느낌이 사라지는가"를 **원리 → 이 프로젝트에 실제로 넣은 값**까지 한 번에 정리한 것이다.
> 표기: 시간은 초(괄호 안은 30fps 프레임), 관절 회전은 라디안(+x = 앞으로 숙임/굽힘), 좌표는 캐릭터 기준(+z 앞, +y 위).

## 목표 1. 캐릭터 외형 — "3D 아바타"가 아니라 "클럽에 온 사람"

### 1-1. 무엇이 인형처럼 보이게 만드는가 (우선순위 순)
| 원인 | 사람 눈에 보이는 증상 | 이 프로젝트의 처리 |
|---|---|---|
| 관절 이음매 | 팔꿈치·무릎에 공이 박힌 듯한 고리 선 | **v40** 이음 구 반지름을 위·아래 통 중 굵은 쪽의 97%로 맞춤 + 굽힌 각도의 절반만 따라 회전(삼각근·고관절 포함) |
| 굳은 손 | 손가락이 막대처럼 곧게 붙어 있음 | **v40** 손가락 2마디 · 손 모양 6종(편안·닿기·감싸기·쥐기·폄·잔 들기) · 새끼 쪽이 더 굽는 계단 굽힘 · 미세한 움직임 |
| 같은 얼굴 | 피부색만 다른 복제 | v38 개인별 두상 조각 · 인종 6분류 골격 · 좌우 비대칭 |
| 인형 비율 | 큰 눈 · 작은 코 · 긴 목 | v38 눈 1.06 · 코끝·콧망울 · 목 1.4cm 단축 |
| 플라스틱 피부 | 고른 색 · 광택 | v38 혈색·색소 얼룩 + 모공 레이어 · 피부톤별 하이라이트 · 피하산란 근사 |
| 굳은 옷 | 치마·옷이 몸과 함께 딱딱하게 움직임 | **v40** 치마 스프링(이동·회전을 반 박자 늦게 따라감, 박자에 미세하게 튐) · v25~ 원단 노멀맵 · 소매/바지 주름 |
| 완벽한 정지 | 서 있을 때 마네킹처럼 멈춤 | 호흡 · 무게중심 흔들림 · 시선 이동 · 손가락 미세 움직임(v40) |

### 1-2. 얼굴 (실사 원칙 → 적용)
- **비율**: 눈 사이 = 눈 하나 너비, 코 너비 ≈ 눈 안쪽 사이, 입 너비 ≈ 동공 사이, 눈은 머리 높이의 절반. 인형은 눈이 1.3~1.5배 크고 턱이 뾰족함 → v38에서 실제 비율로.
- **비대칭**: 좌우 눈 크기 3~4%, 눈썹 높이 ±1mm, 입꼬리 높이 ±0.6mm, 코끝 ±0.8mm 차이(사람마다 다른 값). 완벽 대칭은 "만든 얼굴" 신호.
- **피부 레이어**(아래 → 위): 기본 피부색 → 저주파 얼룩(볼·코 혈색, 색소) → 모공(고주파 어두운 점 + 미세 반사점) → 구조 음영(눈두덩·코 옆·턱 밑) → T존 유분 하이라이트 → 나이 주름(팔자·눈가·이마, 26세 이후 점점) → 수염 자국(면도 후 푸르스름한 그늘).
- **어두운 피부**: 하이라이트를 흰색이 아닌 금빛·약하게, 그늘은 더 깊게, 홍조는 1/3 — 그렇지 않으면 잿빛 화장처럼 보임.
- **눈**: 흰자는 순백이 아닌 따뜻한 회백색, 눈물샘(안쪽 분홍), 윗눈꺼풀이 홍채 위 1/5을 덮음, 동아시아계 몽고주름. 깜빡임 2~6초 간격, 0.12초.
- **진짜 사진 수준**을 원하면: 스캔 기반 인물 에셋(4K 알베도·노멀·러프니스·캐비티, 헤어 카드, 표정 블렌드셰이프)이 필요 — 현재 절차적 엔진의 한계(v38 문서 참고).

### 1-3. 몸매
- 머리 1 : 키 7.5~8, 어깨너비 남 ≈ 머리 2.2개 · 여 ≈ 2개, 팔 끝(손목)은 사타구니 높이.
- 체형 8종(마름·보통·볼륨·통통·운동·근육질·스토키·플러스)과 실제 키 분포(여 1.49~1.75m, 남 1.61~1.89m).
- 근육·지방 분포: 근육질은 삼각근·위팔이 굵고 허리는 그대로, 통통·플러스는 배·엉덩이·위팔 아래쪽이 늘고 손목·발목은 거의 그대로(지방은 말단에 잘 안 붙음).
- **관절**: 실제 팔꿈치·무릎은 "공"이 아니라 굽히면 바깥쪽이 둥글고 안쪽이 접히는 형태 → 굵은 쪽에 맞춘 이음 + 절반 각도 회전으로 근사(v40).

## 목표 2. 커플 행위 애니메이션

### 2-0. 모든 동작에 공통으로 넣은 것 (couple.js · contact.js · motion.js)
1. **6단계**: Approach(다가감) → Alignment(높이·방향 맞춤) → Contact(닿음) → Interaction(머묾) → Release(떨어짐) → Recovery(블루스 홀드로 복귀). 각 단계 가중치는 smoothstep(ease-in-out).
2. **손 목표점**: 상대의 실제 상체·머리 방향 기준 접촉점(허리 옆·허리 뒤·등 위·어깨 위·목 뒤·위팔·볼·앞 허리·맞잡은 손) → 관절 최적화(관통 금지 + 목표 추종)로 손을 놓음.
3. **반응 지연 0.18초**: 받는 사람은 항상 0.18초(5프레임) 늦게 반응 — 두 사람이 똑같이 움직이는 것이 가장 큰 인형 신호.
4. **접촉 반응**: 닿는 순간 받는 사람이 숨을 살짝 들이쉬며 상체 −0.035, 목 −0.04, 머리 −0.03이 0.5초 동안 일어났다 사라짐(감쇠 사인).
5. **체중 이동**: 리드는 다가가며 상체 +0.04, 앞 무릎 +0.05.
6. **박자 스텝**: 블루스 홀드 중 2박에 한 번 좌우로 체중 이동(골반 z ±0.032, 상체는 반대로 55%, 디딤발 반대 무릎 +0.07). 상대는 거울 방향 · 0.06박 늦게.
7. **호흡**: 상체 x에 0.24~0.27Hz 사인(평소 0.008, 이마·키스 같은 가까운 동작은 0.02).
8. **손 모양**: 닿을 땐 펴서 표면을 따라(touch), 볼은 감싸듯(cup), 턴은 맞잡기(grip), 잔은 쥐기(glass).
9. **키 차이**: 큰 사람은 상체·무릎을 숙이고(차이 × 1.1, 최대 0.32), 작은 사람은 까치발(차이 × 0.45, 최대 5cm).
10. **동작 중 전환/취소**: 언제든 다른 동작 또는 「⏹ 지금 동작 멈추기」 → 현재 가중치에서 그대로 섞여 넘어감.

### 2-1 ~ 2-9 동작별 사양 (v40 실제 타이밍)

#### 1) 👂 귓속말 — 3.4초(102f) · 닿음 1.1초(33f)
| 구간 | 리드 | 상대 |
|---|---|---|
| 0~1.1s 다가감 | 상체 앞으로 +0.15, 고개를 상대 귀 쪽으로 돌림(목 40%·머리 60% 분배), 가까운 손은 상대 위팔로 | 0.18s 늦게 시선이 리드 쪽으로 |
| 1.1~2.6s 머묾 | 입이 귀에서 2~3cm, 입 모양 움직임, 위팔 손은 가볍게(touch) | 고개를 반대쪽으로 0.28 기울여 귀를 내줌, 접촉 반응(움찔+숨) |
| 2.6~3.4s 복귀 | 상체가 먼저 돌아오고 손은 0.2s 뒤에 떨어짐 | 미소 표정 유지 후 복귀 |
- 하체: 리드는 앞 무릎에 체중, 뒤꿈치는 바닥에. 상대 하체는 거의 고정.
- 흔한 실수: 머리만 90° 돌리기 → 목과 머리에 나눠 돌리고 상체도 살짝 비틀기.

#### 2) 🤲 허리 끌어당기기 — 3.4초 · 닿음 0.9초
- 리드 손: 상대 허리 뒤 옆(골반 위 13cm, 등 쪽 바깥)으로, 손가락은 펴서 등을 감쌈(touch). 팔꿈치는 바깥·아래.
- 0.9s에 상대 골반이 7~9cm 당겨짐(close .09) → 상대는 0.18s 늦게 상체가 살짝 뒤로(−0.035) 반응한 뒤 손을 리드 목 뒤로.
- 체중: 리드는 뒤꿈치 쪽으로 살짝(당기는 힘), 상대는 앞발 쪽으로.
- 실수: 팔이 상대 옆구리를 관통 → 목표점을 등 바깥 모서리(허리 너비 62%)에 두고 관통 금지 최적화.

#### 3) 💫 한 바퀴 돌리기 — 3.0초 · 회전 정점 1.7초
- 리드: 한 손을 두 사람 머리 사이 30cm 위로 들어 올려 맞잡음(grip), 다른 손은 상대 허리 옆.
- 상대: 들어 올린 손을 축으로 360° 회전(시작은 느리게 · 가운데 빠르게 · 끝에서 감속하며 마주 봄), 치마는 스프링으로 늦게 퍼졌다 돌아옴.
- 실수: 팔이 꼬임 → 손을 머리 위 중심선에 두어 어깨 회전이 한 방향으로만 일어나게.

#### 4) 💃 뒤로 눕히기(딥) — 4.2초 · 닿음 1.5초
| 구간 | 리드 | 상대 |
|---|---|---|
| 0~1.5s | 한 손은 상대 등 위(날개뼈 아래), 다른 손은 허리 옆 · 앞 무릎을 굽혀 중심을 낮춤 | 무릎을 굽히며 상체 −0.62까지 천천히 젖힘 |
| 1.5~3.4s | 상대 얼굴을 내려다봄 · 받친 팔이 무게를 받음 | 목 −0.12 · 머리 −0.18(과하게 꺾지 않음) · 한 팔은 리드 목 뒤 |
| 3.4~4.2s | 일으키며 무릎을 펴고 마주 봄 | 상체가 먼저, 머리는 0.18s 늦게 따라옴 |
- 무게중심: 두 사람의 합성 중심이 리드의 두 발 사이에 있어야 함(리드 앞 무릎 굽힘으로 확보).

#### 5) 💗 이마 맞대기 — 4.0초 · 닿음 1.3초
- 1.3s 동안 천천히 다가감(가장 느린 동작 — 망설임이 감정). 이마 목표 = 상대 머리 중심에서 앞 90%·위 30%.
- 머무는 동안 호흡이 깊어짐(0.02) · 눈 감기·미소. 손: 리드는 허리 옆, 상대는 어깨 위.
- 실수: 머리를 맞댄 채 완전히 정지 → 호흡과 아주 작은 좌우 흔들림 유지.

#### 6) 😚 볼 뽀뽀 — 3.0초 · 닿음 1.0초
- 리드: 고개를 상대 볼 쪽으로(볼 목표 = 머리 옆 95%·앞 30%·아래 30%), 한 손은 상대 어깨 위.
- 상대: 0.18s 늦게 볼을 살짝 내주며(반대로 고개 회전) 접촉 반응, 이후 수줍은 표정.
- 짧고 가벼움: 닿아 있는 시간 0.6s 이내.

#### 7) 🤗 꼭 안아 주기 — 4.0초 · 닿음 0.9초
- 리드: 두 손을 상대 등 위 좌우(어깨뼈 높이)로, 손가락은 펴서 등을 감쌈.
- 상대: 한 팔은 리드 목 뒤, 다른 팔은 등. 고개는 상대 어깨 너머로.
- 닿은 뒤 0.5s 동안 서로 살짝 눌림(접촉 반응) → 좌우로 천천히 흔들림(박자 스텝 계속).

#### 8) 🫂 백허그 — 4.6초 · 닿음 1.5초
- 상대가 먼저 돌아섬(flip) → 리드가 뒤에서 다가가 두 팔을 상대 앞 허리로(배꼽 옆 5.5cm).
- 상대는 0.18s 늦게 리드의 손목·아래팔 위에 자기 손을 올림(손 목표 = 리드 손 위치 + 3cm).
- 리드 고개는 상대 귀 옆(아래로 5cm), 상대는 등을 리드 가슴에 기댐.

#### 9) 💋 키스하기 — 4.0초 · 닿음 1.25초
| 구간 | 리드 | 상대 |
|---|---|---|
| 0~1.25s | 한 손으로 상대 볼 감싸기(cup), 다른 손은 허리 뒤 · 고개를 +0.24 기울이며 입술 목표로 · 키 차이만큼 숙임 | 0.18s 늦게 손을 리드 목 뒤로, 고개를 −0.24(반대) · 작은 쪽은 까치발 |
| 1.25~3.2s | 머묾 · 호흡 깊게 · 눈 감기 | 접촉 반응 후 기대기 |
| 3.2~4.0s | 입술이 먼저 떨어지고, 볼 손은 0.2s 뒤 | 눈을 늦게 뜸 |
- 실수: 정면으로 코가 부딪힘 → 서로 반대로 고개 기울이기(필수).

### 2-10. 나이트클럽 조명·음악과의 연결
- **박자**: 블루스(슬로) 중에는 2박에 한 번 체중 이동 — 동작 버튼을 누르면 즉시 시작하되, 체중 이동 위상은 박자를 그대로 이어감(끊기지 않음).
- **흐름 추천**: 홀드 → 허리 끌어당기기 → 이마 맞대기 → (호감 높을 때) 키스 → 포옹으로 마무리. 신나는 곡에서는 한 바퀴 돌리기 → 딥으로 마무리.
- **조명**: 어두운 플로어에서는 얼굴 실루엣과 손 위치가 감정을 전달 → 머리 기울임·손 모양을 크게 하지 말고 "명확하게".

### 2-11. 키프레임 의사코드 (couple.js 구조 그대로)
```js
// 매 프레임: 모든 기본 포즈가 정해진 뒤, 관통 보정 직전에 실행
e  = now - act.t0;                 // 리드의 경과 시간
eB = max(0, e - 0.18);             // 상대: 반응 지연
w  = smoothstep(0, act.hit, e) * (1 - smoothstep(act.dur - .8, act.dur, e));   // 접근→접촉→해제
plan = {
  hug:   { lead: { L: upperBack(B,-1), R: upperBack(B,+1), pose:'touch' },
```

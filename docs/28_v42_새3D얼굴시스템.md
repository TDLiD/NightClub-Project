# v42 — 새 3D 얼굴 생성 시스템 (예전 얼굴 전면 교체)

## 1. 기술 감사 (교체 전)
| 항목 | 예전 상태 | 문제 |
|---|---|---|
| 두상 | 구(Sphere)를 약하게 조각 | 얼굴 깊이·골격이 거의 없음 |
| 눈·눈썹·입·코 그림자 | **2D 캔버스에 그려 텍스처로 붙임** | "그려 넣은 눈", 표정이 바뀔 때마다 1024×512 텍스처 다시 그리기·업로드 |
| 코·귀 | 작은 구를 붙임 | 따로 붙인 부품처럼 보임 |
| 표정 | 캔버스 다시 그리기 | 입이 실제로 열리지 않음 |
| 피부색 | 매우 밝고 채도 낮은 팔레트 | 마네킹·인형 느낌의 주원인 |
| 머리카락 | 덩어리 껍질(헬멧) | 결·가닥 없음 |

## 2. 기술 선택
- **브라우저(three.js r128)에서 실행 가능한 파라메트릭 3D 형태 모델(3DMM 방식)을 직접 구현.**
- 검토했지만 쓰지 않은 것:
  - MetaHuman: UE5 전용.
  - FLAME: 비상업 라이선스이고 등록 후에만 다운로드 가능.
  - NVIDIA Audio2Face: GPU 서버가 필요하고 웹 실시간 런타임이 없음.
- 실행 중 AI 추론은 없음. 얼굴은 생성할 때 한 번 계산하고 캐시.

## 3. 구조 (`js/face.js`)
1. **정체성(Identity)**:
   - 입력: `look.face`(캐릭터 생성기 값) + 인종 범위 + 나이 + 시드.
   - 얼굴 파라미터 40여 개: 얼굴 폭·길이, 턱 너비·각, 턱끝 돌출·폭·길이, 광대, 볼살, 이마 높이·경사, 눈썹뼈, 눈구멍 깊이, 눈 크기·간격·기울기, 쌍꺼풀, 몽고주름, 눈두덩 처짐, 코 길이·폭·콧대·코끝 방향·돌출·콧방울·매부리, 입 폭, 윗/아랫입술, 인중, 큐피드 활, 귀, 비대칭.
   - 이미 만든 얼굴과 너무 비슷하면 다시 뽑음(`fid` 저장 → 같은 캐릭터는 늘 같은 얼굴).
2. **지오메트리**:
   - 얼굴 쪽에 정점을 몰아 둔 자체 격자에 해부학 변위장 적용.
   - 입술선에서 격자를 실제로 끊어 입이 열림.
   - 안구를 감싸는 눈구멍. 눈 틈 안쪽 피부는 안구 뒤로 숨김.
3. **눈**:
   - 실제 안구: 공막 실핏줄, 홍채 섬유, 동공.
   - 각막: 클리어코트 반사.
   - 위·아래 눈꺼풀 메시가 깜빡임, 찡그림, 놀람을 담당.
   - 속눈썹은 윗눈꺼풀에 붙어 함께 움직임.
4. **입 속**: 구강, 윗니, 아랫니, 혀. 아랫니와 혀는 턱과 함께 회전.
5. **털**:
   - 눈썹: 한 올씩 카드. 안쪽은 위로, 바깥은 옆으로 결.
   - 수염: 콧수염, 염소수염, 턱수염 카드.
   - 면도 자국: 텍스처.
   - 모두 얼굴 모프와 함께 움직임.
6. **피부 텍스처(얼굴마다 생성, 캐시)**:
   - 알베도: 혈색, 색소, 입술, 면도 자국, 주근깨, 점, 검버섯.
   - 노멀: 모공, 나이 주름(이마, 미간, 눈가, 입술 세로주름).
   - 거칠기: T존 번들, 볼 매트, 입술 촉촉.
   - 기존 피하산란(SSS) 셰이더 사용.
7. **실제 피부 반사율**: 지나치게 밝던 팔레트를 실제 피부 알베도 범위로 보정(`realSkin`). 몸 피부도 같이 적용.
8. **머리카락 가닥 카드**:
   - 두피 뿌리에서 스타일별 흐름장을 따라 자라는 알파 가닥 리본.
   - 기존 볼륨 껍질은 속머리 층으로 유지. 덩어리 앞머리 껍질은 가닥 앞머리로 교체.
   - 얼굴 앞은 절대 덮지 않음. 나이 든 남성 일부는 M자 헤어라인.
9. **표정 리그(모프 11개)**: 턱 벌림, 미소 좌/우, 찌푸림, 입 오므림, 입 당김, 눈썹 올림, 눈썹 안쪽 올림, 눈썹 내림, 볼 올림, 코 찡그림.
10. **애니메이션**:
    - 시선 대상: 대화 상대 72%, 근처 사람, 무대, 두리번.
    - 사카드(빠른 눈 이동), 깜빡임, 표정, 말하기 입모양(아·이·우·에·오 순환), 미세표정(눈썹, 비대칭 미소), 숨쉴 때 콧방울.
11. **LOD**:
    - 격자: 근거리 150×116 / 기본 108×84 / 모바일 72×56.
    - 텍스처: 1024 / 512 / 256.
    - 멀면 얼굴 애니메이션을 1/3·1/6 빈도로 갱신하고, 30m 이상은 정지.
    - 피부 텍스처는 프레임마다 하나씩 만들어 생성 순간 끊김을 방지.
12. **연령**: 20대 42% · 30대 30% · 40대 18% · 50~60대 10%. 볼살·입술·눈두덩·팔자·주름·검버섯·헤어라인이 나이에 따라 바뀜.

- `?legacyface` → 예전 얼굴만.

## 5. 한계(솔직하게)
- MetaHuman 수준의 스캔 기반 얼굴은 아님. 웹 실시간 절차 생성의 최상단을 목표로 함.
- 진짜 실사 얼굴이 필요한 근거리 인물은 v41 GLB 하이브리드(`models/humans/`)로 교체 가능. ARKit 블렌드셰이프 자동 연결.
- 시작 화면의 작은 얼굴 미리보기는 아직 2D 그림.

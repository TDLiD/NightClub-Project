# v10 — 부르스 행동을 실제 동작으로

## 무엇이 바뀌었나
v9에서는 부르스 세부 행동이 대사와 호감도 반응만 있었고, 키스 말고는 몸이 움직이지 않았습니다. v10에서는 행동마다 **리드(플레이어)의 손과 팔이 실제로 움직이고**, 이어서 **상대가 몸으로 반응**합니다.

| 행동 | 리드 동작 (0~1초) | 상대 반응 (호감도에 따라) |
|---|---|---|
| 🤗 안아 주기 | 간격 0.30m로 다가가 두 팔로 상대 등(허리 위)을 감싸 안고 고개를 어깨 쪽으로 | **수락:** 목 뒤로 팔을 두르고 어깨에 기댐 / **거절:** 두 손으로 가슴을 밀어냄 |
| 💋 키스하기 | 두 손으로 허리를 감싸며 얼굴을 가까이 | **수락:** 서로 고개를 반대로 기울여 입맞춤, 하트 효과음 / **거절:** 고개를 옆으로 돌림 또는 밀침 |
| 🍑 엉덩이 만지기 | 간격 0.28m, 허리에 있던 오른손이 엉덩이 옆 뒤쪽으로 내려감 | **제지:** 뒤로 손을 뻗어 그 손을 잡아 치움 / **거절:** 뺨, 리드가 움찔, 춤 중단 |
| 🫳 가슴 만지기 | 오른손이 상대 가슴 앞쪽으로 이동 | **제지:** 손목을 탁 잡음 / **거절:** 뺨, 춤 중단 |
| 👚 옷 벗기기 | 두 손으로 허리 앞 옷자락을 잡고 위로 올리려 함 | 두 손으로 손목을 붙잡아 내림(옷은 벗겨지지 않음, 노출 표현 없음) / **거절:** 뺨, 춤 중단 |

반응을 가르는 기준(호감도·키스 여부)은 v9와 같습니다(`docs/17` 표 참고). 원하지 않는 스킨십은 언제나 호감도가 떨어지고, 뺨을 두 번 맞으면 손님이 방을 나갑니다.

## 구현
- `motion.js` `BLUES_ACT(p, u)`: 부르스 기본 자세 위에 `u.bAct = { k, t0, dur, out }` 시간 구간별 목표 자세를 섞습니다. 구간 곡선은 `env3`, 관절 보간은 `mixJ`를 씁니다.
- **관절 각도 = IK:** 브라우저 안에서 실제 리그로 정운동학을 돌려, 손이 목표점(상대 기준 앞뒤·좌우·높이)에 닿는 어깨(x, y, z)와 팔꿈치 각을 격자 탐색과 국소 개선으로 찾았습니다. 측정 오차는 1~5cm입니다.
  - 기본 자세: 리드 손은 상대 허리 옆, 상대 손은 리드 어깨 위
  - 포옹: 리드 손은 상대 등 뒤(−12cm), 상대 손은 리드 목 뒤
  - 엉덩이: 상대 엉덩이 옆 뒤쪽(높이 0.85m) / 가슴: 상대 가슴 앞(+13cm)
  - 옷: 허리 앞 → 들어 올림, 상대 손은 리드 손목
- `karaoke.js` `ACT` 표: 행동마다 길이·반응 시점·간격 조절 값을 정합니다.
  - 동작 시작 → `hit`초에 반응(대사, 제스처, 호감도) → `dur`초에 종료
  - 동작 중에는 칩이 ⏳로 잠겨 연타를 막습니다.
- 부르스 중 보정
  - `music:drop`과 구역 트리거로 나오는 환호 모션을 무시합니다.
  - 들고 있던 잔을 숨겼다가 춤이 끝나면 되돌립니다.
  - 곡이 끝나면 다음 슬로곡으로 자동으로 이어집니다(발라드 ↔ R&B).
- 조정 포인트
  - 반응 기준: `karaoke.js` `REACT`
  - 타이밍·간격: `ACT`
  - 자세: `motion.js` `BLUES_ACT`

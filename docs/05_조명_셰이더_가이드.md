# 05. 조명 · 셰이더 효과 설정값 가이드 (Three.js / Unity URP·HDRP / Unreal 5)

> 이번 버전 목표: **"어둡지 않고 화사한 나이트"** — 바닥·벽·인물이 잘 보이는 밝은 베이스 위에 컬러 조명을 얹는다.
> 구현: `public/js/core.js`(렌더러) · `public/js/world.js`(조명·이펙트)

## 1. 밝은 베이스 (가장 중요)
| 항목 | Three.js (현재값) | Unity URP | Unreal 5 |
|---|---|---|---|
| 색공간/톤매핑 | `outputEncoding = sRGB`, `ACESFilmic`, exposure **1.3** | Linear, Tonemapping ACES, Post Exposure +0.6 | Filmic, Auto Exposure **Off**(수동 EV100 ≈ 3~4) |
| 앰비언트 | Ambient `#c9bcf0` 0.52 | Environment Lighting Color `#9a8cc8` intensity 1.0 | Sky Light 1.5 (cubemap: 클럽 HDRI) |
| 헤미스피어 | 하늘 `#e2d6ff` / 바닥 `#5b4580`, 0.62 | Gradient(Sky/Equator/Ground) | Sky Light Lower Hemisphere Color |
| 안개 | `FogExp2('#3a2a5e', 0.0075)` | Fog Exponential² 0.008 | Exponential Height Fog density 0.02, Volumetric On |
| 바닥 | `#3a2f55`, roughness 0.32 (광택) | Smoothness 0.7 | Roughness 0.3 + SSR |
| 벽 | `#5a4a8a` roughness 0.85 | — | — |
> 원칙: 어두운 배경(#07030f) 대신 **중명도 보라 계열**을 바탕으로 쓰고, 노출을 올린 뒤 조명 색으로 분위기를 만든다. 인물 피부가 회색으로 죽지 않는 것이 기준.

## 2. 미러볼
| | Three.js | Unity | Unreal |
|---|---|---|---|
| 볼 | Icosahedron(1.1, detail 2), metal 1, rough 0.1, `flatShading`, emissive `#3a3a66` | 동일 + Reflection Probe | Static Mesh + Metallic 1 + Roughness 0.05 |
| 반사점 | `Points` 200개 + 소프트 도트 텍스처(가산 혼합), 매 프레임 볼 회전각으로 방향 회전 → **방 벽/바닥 박스에 투영** | Particle System (Shape: Sphere, Rotation over lifetime) 또는 Cookie Spot Light 6개 회전 | Light Function Material(구형 점 패턴) + Rotating Movement |
| 회전 | 0.5 rad/s | 30°/s | Rotation Rate Yaw 30 |

## 3. 무빙 스팟 + 빔(볼류메트릭 흉내)
- SpotLight ×4: intensity 2.0~2.9(비트 킥 +0.4), distance 46, angle 0.36, penumbra 0.55, decay 1.1
- 빔 메시: 열린 원뿔 `Cylinder(0.05, 1.8, 11)` + `AdditiveBlending`, opacity 0.075, depthWrite false → 헤이즈 속 광선처럼 보임
- 타겟 궤적: `(cos(t·0.55+k·1.6)·7, 0, −8 + sin(…·1.3)·5.5)` — 리사주 곡선으로 겹치지 않게
- Unity: HDRP Volumetric Fog + Spot "Volumetrics" On / URP는 빔 메시(Additive Shader Graph, Fresnel로 가장자리 감쇠)
- Unreal: Spot Light → Volumetric Scattering Intensity 2~4

## 4. 레이저
- 12가닥, 원점 (0, 7.6, −18.9). 얇은 원통(r=0.016, 길이 38), 가산 혼합.
- **박자 동기화**: opacity = 0.25 + 0.45 × (1 − beatPhase) / 2마디마다 패턴 4종(부채꼴 스윕, 개폐, 상하 웨이브, 휴식) / 4박마다 색상 hue +0.17
- Unity: LineRenderer + HDR Emissive(Intensity 6) + Bloom / Unreal: Niagara Beam + Emissive 50

## 5. 헤이즈(연기·Fog)
- 스프라이트 30장(소프트 도트, 가산, opacity 0.055~0.075, scale 6~11)이 스테이지·댄스플로어 위 0.6~3.6m에서 천천히 드리프트
- 실제 볼류메트릭이 비싼 웹 대신 **"빔 메시 + 헤이즈 스프라이트"** 조합으로 연기 속 조명 느낌
- Unity HDRP: Local Volumetric Fog(3D Texture 노이즈, scroll speed 0.1) / Unreal: Volumetric Fog + Niagara 스모크(라이트 파티클)

## 6. 네온 사인 · LED
- 네온: 캔버스 텍스트 + `shadowBlur 24` 글로우를 텍스처에 굽고 `MeshBasicMaterial`(톤매핑 영향만) → 블룸 없이도 빛나는 느낌
- 띠 네온: `emissive` 1.2~2.0 박스. (블룸을 쓰면 emissive 3~5로 올리고 threshold 0.8)
- LED 월: 512×160 캔버스에 이퀄라이저·문구를 **15fps**로 다시 그려 CanvasTexture 갱신(비트 연동)
- 댄스플로어: InstancedMesh 60타일 + `setColorAt` HSL 물결 + 비트마다 체커 플래시

## 7. 성능 예산(웹)
| 항목 | 예산 | 현재 |
|---|---|---|
| 동적 라이트 | ≤ 12 | Spot 5 + Point 6(+VIP 3) |
| 드로우콜 | ≤ 450 | 약 430 (아바타 메시 병합·장식 인스턴싱 적용) |
| 텍스처 | ≤ 64 | 약 40 |
- 모바일 저사양 대응 아이디어: 스팟 빔/헤이즈 off, 반사점 200→60, 픽셀비율 1, 레이저 6가닥.
- 블룸(UnrealBloomPass)은 효과는 좋지만 모바일 비용이 커서 기본 비활성(데스크톱 옵션으로 추가 권장: strength 0.6, radius 0.4, threshold 0.85).
